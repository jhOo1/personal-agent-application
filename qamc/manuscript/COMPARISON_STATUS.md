### Which stage changed the fresh RPEval ranking?

Crossing both frozen route vectors with both deployments' endpoint grades isolates the effect of the binary routing decision. On the 17 jointly valid tasks (87 positions), either route vector gives exactly −2 matched positions against full RP with deployment one's endpoints and +4 with deployment two's. All six positions of movement in the aggregate trace to three all-ignore tasks on which both selectors chose empty history. Net differences for implicit/009 moved +2 to 0, implicit/000 moved −4 to 0, and explicit/061 moved 0 to +4. The sole change of route, implicit/057, had identical position Match across all four endpoints. One other allocated task has an invalid Match and stays missing. The result identifies variation downstream of the binary switch. Full-history generation also uses fresh estimated preferences, and both answers and grading were regenerated, so this replay cannot allocate the variation to a single model call. It provides no evidence for changing the switching threshold to fix the observed reversal.
