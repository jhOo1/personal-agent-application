# RP 策略重编译与候选集合依赖

阶段评审提出两个可分开的假设。第一，归档 RP 预测可约束旧联合规划中已经声明的记忆作用。第二，RP 受其他候选干扰，对同一个当前任务和历史来源给出不同作用强度。这里分别复用旧规划和旧排序，真实新增请求与评分均为零。

## 1. 旧规划的策略重编译

读取 233 道冻结开发题。221 道具备可重放计划，8 道原规划交付未知，4 道未通过规划合同。以归档 RP 实际 Actor 请求中的逐来源预测为准，核验哈希、原文和 ID 顺序。程序保留 TASK 硬条件、预测 B 的软排序作用和预测 C 的已有硬条件。预测 A 的作用及预测 B 的硬排除被拒绝。预测 C 的软影响记为作用强度未决，程序无法凭空推导它对应的硬约束。此路径只读原规划和归档预测。

两边均用同一求解器，固定候选文本、模型原选择和 Actor 提示。这一点与网页版初稿里直接用 RP 约束编译器对比模型自选的提法不同。同求解器比较可以把 30 道选择变化归因于结构化作用修改。与原模型自选相比变化的 64 道另外记录。

| 可核验结果 | 数量 |
| --- | ---: |
| 去掉预测 A 的排序条款和硬条款 | 441 + 3 |
| 去掉预测 B 的硬排除 | 52 |
| 保留预测 B 的排序条款 | 957 |
| 保留预测 C 的已有硬约束 | 171 |
| 标记为强度未决的预测 C 软条款 | 163 |
| 已有硬约束的预测 C 来源 | 77/103 |
| 实际选择变化 | 30/221，18 个来源组 |
| 条款变化且选择相同 | 170/221 |
| 与原始 Actor 清单不同的请求 | 200 道，199 个去重请求 |

重编译后仍有 119/221 道的已选组合，命中被删除的预测 A 软条款原先支持的选项，原求解为 134 道。同一选择也可能由当前任务独立支持，不能把这个计数当成误用。常见的可行性缺口是 26 个预测 C 在固定候选中没有可执行硬约束。固定选项文本也可能已经吸收了被拒绝的历史，且 Actor 仍可看到原文。这个重编译可作显式条款的消融。全量重生成需要最多 199 个去重 Actor 请求及相应评分，当前证据只隔离了条款对程序选择的影响。

在 `explicit/007`，重编译让 D5 从居家野餐回到正式餐桌。其余选择与原联合臂相同。RP 自己仍把用餐效率、外卖及灵活组合等三条作者 A 预测为 B。这个例子显示重编译能删除某一处影响，同时继承预测层误差。

## 2. 归档 RP 的候选集合依赖

另从正式已运行的 300 题中核验具备完整双路排序的 296 道、1,578 个位置。以当前 Query、Context、事实和某条记忆原文的逐字值组成配对键。其他候选按原文比较，要求两个请求的候选多重集合不同。逐题把融合、MLE 和 IPE 首选绑定到实际原文位置及 Actor 请求哈希。作者标签用于检查各组的可比性。

| 观察 | 精确任务–记忆组 |
| --- | ---: |
| 档案中出现不同候选集合 | 219 |
| 同一配对键的作者标签一致 | 219 |
| 融合标签改变 | 55，来自 31 个来源组 |
| 融合的准入改变，有一次为 A、另一次为 B/C | 53 |
| 融合改变按作者 A / B / C | 53 / 1 / 1 |
| MLE 首选改变 | 54，来自 28 个来源组 |
| IPE 首选改变 | 51，来自 29 个来源组 |
| 有同位置对照／同位置发生融合改变 | 79 / 11 |
| 同位置且候选数也相同的融合改变 | 1 |

例如 `explicit/000`、`explicit/001`、`explicit/065` 共用一个精确任务–记忆键，作者均为 A。实际融合 B、A、B，对应 MLE/IPE 首选 B/B、A/B、B/A。这三个请求的候选数分别为 9、9、6，焦点记忆位置也变化。现有档案呈现真实的预测不稳定，尚不能区分其他候选的内容、数量、顺序及模型生成变动。作用稳定性也有条件。真实存在冲突、不同主体或共同约束时，另一条历史有理由改变当前记忆的作用。

## 3. 研究取舍

RPEval 先生成 Query，再按不同意图反向构造偏好。多偏好设置在固定 Query 下组合带不同适用性的偏好，并过滤冲突。RP 的 MLE 已用假设意图下的反事实表达来估计 Query 似然，IPE 则估计偏好先验，最后融合排名。两者的结构相近属于可核实的观察。由结构相近推断 RP 在真实任务中过拟合还需要独立证据。 [RPEval 论文 §3.1、附录 B.4](https://arxiv.org/html/2601.16621v1#S3.SS1) · [RP-Reasoner §4.1](https://arxiv.org/html/2601.16621v1#S4.SS1)

当前有区分力的实验变量是**候选隔离**。给判别器当前任务、受影响的人和一个焦点来源，求证它能否改变一个已有决定，再把通过的证据合并执行。只在事先识别的矛盾或共同约束处联合检查。以相同提示、模型和焦点判别次数的全候选可见臂为机制控制，以冻结 RP 和强 Gate 为端到端对手。匹配时固定焦点位置和候选数或显式平衡它们。已曝光的 219 组重复键可检验一致性，不能按旧分挑选其中的 55 组作为性能面板。主效果必须使用更宽的已曝光同题原生面板，合法 B/C、OPB、UPB、FM 和真实成本共同决定是否继续。

重编译可以减少合法性未经核验的显式作用，在旧规划中主要改变了输入文字。当前优先验证作用判别是否能取得独立证据，再决定是否值得派发联合规划消融的 199 个新 Actor。此报告没有新的端到端分数。RP、原联合规划及原生评分归档继续作为固定参考。
