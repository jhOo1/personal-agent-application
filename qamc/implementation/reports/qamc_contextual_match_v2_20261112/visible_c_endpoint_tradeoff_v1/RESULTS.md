# 可见合法约束与整组清空历史的取舍

在可核验的 IPE-C 有史子集中，清空历史大幅减少自动裁判的过用严重度，但带来更多漏用和可行性问题。它适合作为对照。这个结果收窄了共同机制的目标：需要同时改变导致风险的具体行为和保存合法约束，仅压低过用分不足以晋级。

## 冻结档案复算

从 [原文送达审计](../retained_c_realization_v1/RESULTS.md) 的 107 个作者 C 且 RP 执行 C 的位置开始，共 87 道已曝光 RPEval 题。脚本从原始 RP 归档重新计算成稿哈希，同时核验两套哈希序列化口径。85 道的 IPE-C 精确采用同一有史 RP 成稿，涉及 105 个已核验送达位置。其余两道未采用该稿。85 道中 6 道缺有效配对，79 道进入主表。脚本不读取封存数据，不派发模型请求，也不修订旧分。原分来自 [冻结的双端点对照](../ipe_c_two_endpoint_completion_v1/READOUT.md)。

共同有效的 OPB 严重度总和从 138 降到 36，UPB 从 51 升到 253，FM 从 14 升到 178。它们是旧评分字段的加总。即使事后逐题用 Match 选择是否清空，给 IPE-C 的回放收益也只有 6 位。这一上界只覆盖已存无历史成稿和当前筛选子集。筛选条件本身包括已确认的合法 C 与 IPE-C 有史执行，不能用这些数字估计所有问题的开关效果，也不能逐条归因给指定 C。

真实行为可以和总分分离。原八根审计中，RP 已收到并保护无布艺、无卡通、无辣配料等要求。云南家庭路线的原文明确排除菌类，RP 已收到 C，仍未在米线汤底和配菜等决策点落实核验。强 Gate 和 C5 落实了该核验，三份回答的整题 Match 都是 4/7。现有证据无法确认商户食材。

## 基准取舍

- **RPEval 保留为混合偏好主基准。** 同题清空反证表明，全史与无史两端缺少同时保护软偏好和硬约束的能力。既有误用裁判会给完全无史的成稿记 OPB，因此论文还需要并列报告可审计的实际行为，不能把全部 OPB 解释成历史引起。
- **PersistBench 保留为风险与效用主基准。** 选择性暴露已在公共科普和欢迎邮件两个迎合来源产生双适配裁判可观察的实改；严格 BU 新面板的 Qwen 回归和未复现的原始 Kimi 协议限制主张。优先提升这个正向机制的可比较性。
- **BenchPreS 继续作正式交付回归，移出共同算法的晋级门槛。** 固定公开快照中同画像同偏好的 37,050 次比较均未观察到适用标签翻转。固定强 Gate 的 38 道共同题中 AAR 58/68，新反馈未升分且降完整度；部分偏好已到 Actor 仍未落实。它保留了评测正式交付的独立价值。未发现多个基准在同一决策上要求相反行为的证据。

[PairPref 原文](https://arxiv.org/html/2609.34526) 的 1,227 对固定偏好、请求和回复池，只改变情景，适合检验同一条偏好随受益人、同伴或资源约束变化而翻转。附录给出拼桌共享与独自用餐的配对实例，并记载发布文件名和原始配置。本次未定位到可直接核验的作者数据下载、固定代码版本与评分脚本，因此只列为替代候选。论文中的附录样例不构成可复现实验集。确认工件后才考虑运行，正式交付回归材料继续保留。

基准取舍和替代条件已发 QAMC-v3.2 交叉审议。当前结果为 0 次新增 Actor、0 次新增 Judge、0 新评测样本。未读取封存集。没有 SOTA 或独立确认新主张。
