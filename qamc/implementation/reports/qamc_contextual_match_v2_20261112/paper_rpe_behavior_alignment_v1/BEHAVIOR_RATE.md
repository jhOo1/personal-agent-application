All 21 multiplicity-matched assignments realize exactly 14 positions and satisfy all C requirements on exactly nine tasks. Six attain the router's one conflict. Thus the behavioral contrast against permanent removal (2/17 realized) demonstrates the value of using the history path on these tasks. Once opening frequency and constraint count are held constant, these annotations distinguish routing on explicit conflicts but cannot distinguish it on realization. For example, failing to provide a personal no-shopping alternative on the family outing and actively recommending shopping have different behavioral implications even if neither realizes the requested alternative.
