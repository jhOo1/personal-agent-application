### Measurement and interpretation

The five preference judges each receive one attribute and the answer. The completeness judge receives the original task and the answer. Neither gets the Actor’s fixed facts. A high completeness rating can therefore coexist with an unsupported attendance claim. The paired quality reading above is a separate diagnostic from the frozen Qwen adapter scores. The request constructor is in proposals/qamc_memgate_external/evaluation.py (initial_requests).

Inspection of all 13 distinct archived Actor requests in draw 0 found an additional transfer limitation. The shared system text explicitly identifies the assistant as Qwen and includes a generic concise-response example in its tool instructions. DeepSeek received this same text. The comparison measures substitution into the deployed Qwen prompt. A future model-neutral prompt comparison would answer a different question and would need matching fresh control arms. If probing removal of a target preference, remove its actual selected source from the system memory block and its corresponding user-message guidance together; keep generic instructions fixed across arms and verify whether remaining evidence still expresses the same preference. A single-field deletion would leave an exposure path open.

### All first-draw target-label improvements

Both additional objective-expression follows were in the same profile. Neither concise target improved. This is a post-score reading of all improved targets for this draw.

- Admissions performance variation (2d6ba4ff). The new DeepSeek letter gives the committee a template with blanks for the semester, cause, subsequent grades and applicant name. It also says later coursework demonstrates sustained performance. No filled-in academic timeline supports this narrative. Qwen produces a signed message but connects professional responsibilities to academic fluctuation without an established causal link. The preference judge credits DeepSeek for objective expression; this does not settle whether the applicant can send the letter as written.
- Denied health-insurance claim (87081169). Both answers say supporting documents are enclosed and medical necessity is established. The shared request provides no evidence for those attachments or for that conclusion about this service. DeepSeek additionally asserts coverage under the plan and review of plan terms. It receives the objective-expression credit. These are observable grounding issues in both arms, with a new coverage assertion in the credited answer. This review assesses input support, not the actual legal or medical merits of the appeal.

Thus both target wins count in the prespecified automatic score. Neither demonstrates a verified factual repair on this draw. They do not explain the second or third draw.
