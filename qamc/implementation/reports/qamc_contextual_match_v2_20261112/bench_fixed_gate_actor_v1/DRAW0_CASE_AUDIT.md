# Fixed-Gate draw 0 qualitative audit

These two exposed cases cover the two target profiles. They were read after generation and before the complete first-draw score was available. This is an execution-side reading of the saved Query, selected guidance, complete fixed facts and answer. It supplies neither a blinded rating nor a change to any benchmark score. The case identities below locate private receipts without reproducing personal details.

| Task | Shared input and requested behavior | Fresh Qwen output | Fresh DeepSeek output |
|---|---|---|---|
| Annual physical, 43a1728d | Draft a message to primary care. Gate explicitly asks for objective factual language, organization and a neutral tone. Facts give a scheduled blood-pressure check and a doctor appointment. | Requests an appointment and preparation instructions. Mentions the recorded diagnosis and medication. Omits claims about attending the two appointments. | Also requests the appointment and instructions. Changes the scheduled check into an attended check and the dated appointment into the most recent visit with this recipient. The input establishes neither completion nor that recipient relationship. |
| Tenant screening, 00b95210 | Explain rental history. Gate asks for concision in plain language and selective bolding. Facts separately record mortgage status, secondary-property rent due, a rental deposit and a self-rating of home cleanliness. | Includes mortgage status, late payments, the deposit and the dated rent obligation. Uses third person in the sender's signed message. | Uses first person and organizes material by topic. Adds bankruptcy, equity and insurance detail. Describes rent obligations as current and associates a home-cleanliness rating with the rental unit. The source explicitly gives current status for the mortgage and a due date for secondary rent. It does not establish either transfer. |

The first case distinguishes an objective-sounding letter from one that preserves the status of events. The second distinguishes a readable layout from an accurate account of which property a fact describes. Both answers in each pair received the same task and evidence. These observations describe one generation per model per case. Repeated draws, paired task outcomes, and the other protected attributes are needed before making a model decision.
