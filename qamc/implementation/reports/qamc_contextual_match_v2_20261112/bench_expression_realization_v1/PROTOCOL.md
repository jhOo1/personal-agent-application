# Preserve the task while simplifying BenchPreS expression

The archived Strong Gate answer, accepted history, current task, and scoring are the base. Compare a frozen specialist with one ordinary Qwen edit request. Both see exactly the same eligible sentences and can propose one replacement per sentence. Both pass through the same literal protections and bidirectional entailment test. Only text at previously identified sentence offsets may change. Headings, formatting, salutations, signatures and all other text stay byte-identical. Existing errors in the original are outside this operation's correction scope.

The initial design names MUSS. This implementation uses the author-published TS-T5 4-token English simplifier, whose pinned safetensors release can run locally with the existing Transformers installation, and an already pinned mDeBERTa NLI checkpoint. The TS-T5 paper and model card describe sentence-level Wikipedia-style simplification. Testing English professional communication is a transfer experiment, and the selected 2020 weights are the authors' converted snapshot. This implementation is not a MUSS replication. The research-only checkpoint license is CC BY-NC 4.0. No new weight training. Code, revisions and aggregates can be published separately from model files. [TS-T5 paper](https://aclanthology.org/2021.inlg-1.38/) · [Author checkpoint](https://huggingface.co/kcsheang/ts-t5-base-4tokens) · [NLI model](https://huggingface.co/MoritzLaurer/mDeBERTa-v3-base-mnli-xnli) · [MUSS](https://aclanthology.org/2022.lrec-1.176/)

The pilot has eight exposed tasks: four archived non-bold brevity misses with the actual preference visible in Strong Gate, two previously realized brevity tasks covering both eligible profiles, and two tasks drawn by fixed hash from other profiles for abstention protection. The four misses belong to one profile. Scores and author annotations only select the offline development panel and interpret outcomes. At deployment the trigger sees only the exact original query and already selected original sources. Requests asking for comprehensive detail block simplification. Both generators see only the ordered editable sentences. No preference label, case ID, benchmark category or grading signal is an inference input.

The candidate must shorten both character and word length and preserve known uppercase anchors, numerical strings and selected polarity, condition and commitment tokens. The NLI probability for entailment must reach 0.75 in both directions. This is a model check of semantic similarity, with possible false accepts or rejects. Content preservation is an empirical protection, not guaranteed by these checks. Every declined proposal preserves the original sentence. An exact preserved draft reuses its verified original grade. A failed cloud edit response remains unavailable and does not count as a semantic error. Report both logical and physical calls, local model work, scores, availability, and accepted edits. Use the common BenchPreS Qwen adaptation and unchanged comparison with archived Strong Gate. No original Actor calls and no sealed data.

Advance a version only if it repairs the target attribute on multiple tasks and yields practically useful improvements without protected factual, style or delivery regressions. Do not infer replication across profiles from multiple tasks in the same profile. Compare against the ordinary operation before considering widening. On no-op or score ties report coverage and direct text observations.
