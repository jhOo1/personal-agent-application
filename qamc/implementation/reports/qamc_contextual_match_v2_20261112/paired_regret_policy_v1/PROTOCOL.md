# 最后一轮前的第 1 版 · 配对收益决策列表

按第一轮指定对话建议，离线优化固定生成路径的选择，不增加 Actor 或评分。T 为归档无历史路径，H 为 RP 历史路径，G 为现有强 Gate。KEEP 是已冻结 IPE-C 根据 IPE 中是否有 C 决定 T/H。所有基准共享同一选择函数和动作语义；各基准冻结适配器的模板不完全相同。PersistBench 的 T 是作者无历史路径，须经真实送达回执和评分请求哈希核验，不把它等同于 RPEval 模板。动作成本与归档参照如实披露。假如部署，新路线必须先算 MLE 和 IPE，选择 G 时仍要运行原 Gate Selector，已有离线回放不能测到真实在线延迟。

输入只用已经保存的 MLE、IPE 与融合排序，核对 RP 保存报文身份。数量、最高等级占比、两个估计器分歧及 C 的相互支持是有限输入。模型不会看成稿、作者标签、得分、基准名、题号、画像标识、归档有无及同题最佳动作。只拟合策略规则，不更新模型权重。原强参照分别为 IPE-C、Strong Gate、PB_RUBRIC。按已曝光 RPEval 保守来源组、BenchPreS 全画像、PersistBench 来源组分别固定散列分三折，每个外折仅用其余两折的成绩拟合，对 RPEval 拟合时排已知评分旗标。三折合并为组外开发回放，不冒充独立确认。

最多两条单阈值覆盖规则，按倒数一个到两个阈值条件执行，不符合则沿用 IPE-C。阈值来自训练折特征不同取值的 25/50/75 分位点，两侧都进入搜索。优先最大化三基准对各自强参照的最小归一化主收益，再比较平均，最后倾向更短规则。覆盖规则的实际变化至少覆盖三个来源组，两个正增益，删掉任一组仍有正净收益。主指标及保护项均须在训练折相对强参照不降。RPEval Match 分母为位置数，保护 A/B/C 分层 Match 和 OPB/UPB/FM；BenchPreS AAR 分母为合法属性数，保护 MR、完整度、非加粗 AAR；PersistBench 各失败口径用样本计数，保护每个类别及严格 BU。普通搜索使用相同特征、阈值和动作，最大化跨基准归一化平均主收益，无组支持约束。若无可行保护策略，明确标记失败，输出 KEEP 仅供原方法对照。仅在事先有 T/H/G 全部有效且参照有效的集合中比较，不用单臂缺失替代语义失败。该回放不能估全量缺失率之外的真实可得性。

同样按固定原生分和保护项求每域用 T/H/G 的逐题受约束事后上界，清楚标明这不是可部署方法。新方法晋级须见实际组外回放相对各强参照无保护项退步，有至少一个域主指标改善，收益不只来自一个来源组或带旗标。若无可行组合，定位出差距基准及原始动作空间，而后再按用户规定进行第二次也是最后一次设计交流。
