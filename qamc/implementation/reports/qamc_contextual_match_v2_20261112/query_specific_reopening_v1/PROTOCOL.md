# Source specificity as a reason to reopen history

On the existing exposed RPEval 300-task endpoint panel, retain the original IPE-C route unless its valid closed route has an archived RP request with a usable signal. A predicted B/C source must overlap the task more strongly than every predicted A source in this task, and score strictly higher against the current query than every distinct query from other source groups (exclude exact duplicates). Use cosine on sets of alphanumeric Unicode character bigrams within words after lowercase normalization. Require positive overlap. No threshold search, online grades, author labels, new retrieval, or new prompts. The comparison bank contains only exposed development queries. Use source grouping only to keep related development examples out of the reference bank. At deployment a new group would compare against the frozen query bank.

If triggered, select the exact RP full-history endpoint. Otherwise use the exact original IPE-C endpoint. A simpler control uses only the within-task comparison. Report available paired endpoint scores and separately the triggered cases with missing outcomes. Eligibility and fit on this panel are exploratory. Count independent source groups and all-A errors as well as total Match, OPB, UPB and FM. Do not change the rule after reading grades.
