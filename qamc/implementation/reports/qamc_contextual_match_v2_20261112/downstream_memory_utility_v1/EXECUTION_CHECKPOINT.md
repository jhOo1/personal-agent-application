# CAR pilot execution checkpoint before native scoring

The 23 registered history-conditioned donor requests succeeded. All 23 donor answer texts differ from each task's empty-history, full-history and fixed strong answers. The next stage consists of 69 registered requests. The three controllers' user packets and generation parameters match byte for byte within a task. Their system instructions differ by the final edit contract. Eighteen strong fallbacks duplicate an endpoint. The protected-literal extractor yielded an empty list on all 23 tasks, so this pilot cannot empirically validate a literal guard. Copy mode still preserves the exact unaffected blocks by construction.

An execution-side review of five verified nontrivial copy operations found different kinds of behavior:

- In the Spanish travel task with a legitimate pronunciation preference, the proposed dictionary entry is already present in the task-only endpoint. The new donor instead recommends multiple pronunciation tools and omits the proposed dictionary. The final copy operation inserts the existing task-only dictionary block into the full-history answer. This example can test integration of existing candidate text. It does not show that a new donor realized the proposed action.
- In the paired family museum task, the proposal cites a nightlife habit and asks for an optional museum evening route. The donor retains a daytime visit and adds optional night activities. The copy transfers those paragraphs rather than the requested museum evening route. Whether such a transfer is justified by the actual family task must be evaluated separately from the presence of a cited source.
- In a family driving-vacation task, the proposal concerns adding an optional meal preference. The actual donor changes geography and the copy package inserts multiple destination alternatives. The program enforces valid ordered block copies. It does not enforce that a change preserves the method's intended behavioral scope.
- The other executed copies change a section of children's-room organization advice and add a preferred-name line to a legal document. Their effect on native preference scores and task requirements is pending. These examples are de-identified paraphrases.

At the last read-only snapshot, 68 of 69 controller calls had returned successfully and one remained in flight. Five nontrivial commits had been accepted, four using the newly generated donor and one using an archived endpoint. Two requested commit programs had fallen back. The terminal result may add another row. These examples and counts are execution-side observations with no human or independent behavioral ratings.
