# CAR three-benchmark development pilot

Freeze 28 previously exposed tasks and 24 source groups. Four RPEval groups are original tasks with matched all-A and added-B variants. Keep both variants and never use their pairing in inference. Add two held-out-in-this-panel all-A and two C groups from the exposed development pool. BenchPreS spans eight profiles with up to four chosen from profiles whose Strong Gate has existing AAR headroom. PersistBench has three beneficial-use, two cross-domain and three sycophancy groups. Selection is deterministic and frozen before generation. These are development observations and cannot establish independent confirmation.

The three final controllers get identical public task facts, original histories, complete empty-history and full-history proposals, one optionally generated donor, a fixed strong fallback, and mechanically recoverable protected literals. They receive one Qwen3.8-flash call each under the same settings and capacity. WHOLE selects a complete candidate. FREE may select or freely deliver a complete revision. COMMIT may select or copy one donor's ordered, nonoverlapping existing blocks into a base, preserving the untouched blocks verbatim. A program equal to an existing full candidate counts as selection if explicitly selected. RPEval's donor exposes the cited sources and promotes a cited archived A to supporting B. BenchPreS uses the native bounded generation-guidance slot to propose a source-linked action. PersistBench has no such slot and varies the original history slot alone. No author label, scores or raw judge result are included in the proposal, donor or final controller requests.

All arms retain the same declared literal guard and exact strong fallback. Invalid proposal and failed donor delivery leave all three final arms missing for that task; a valid no-intervention proposal permits the ordinary endpoints and fallback in all arms. Downstream contract rejection uses the fixed fallback. Transport failure remains missing. Exact previously archived Actor wires and original grades are reused and separately accounted for. Generation or grading not present in the archive uses the existing paced journal and benchmark-specific scoring contracts. No automatic retries. The known provider-adaptation caveats still apply. The manifest and raw completions stay private in the original research workspace.

Report original IPE-C, Strong Gate and PB_RUBRIC against all three arms, with same-task intersections and common denominators. Report RPEval Match and groups, OPB/UPB/FM, A-only and B/C. Report BenchPreS MR, AAR, completeness and non-bold preference implementation. Report PersistBench strict beneficial use and cross-domain/sycophancy failures separately. Inspect actual interventions and newly composed outputs; do not use score changes alone to claim a protected action. Advance the copy-only mechanism only if it beats both same-budget controls with observable protected benefits on multiple groups and no credible degradation of legitimate preferences, strict beneficial use or task completion. Retain all missingness, contracts, paired baseline comparisons, logical and actual calls and usage. [Prototype](CAR_PROTOTYPE.md)
