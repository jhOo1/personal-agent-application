# Separate-source test of participant requirement protection

Use 21 archived exposed tasks and exclude every source group used in the 14-root open-choice and participant-veto studies. The fixed original pool is the 92-task strong-answer archive. Sort by a fixed UID hash, taking three RPEval all-A, four B-only, four with C, two PersistBench examples of each category, and four BenchPreS profiles. These are new groups relative to the pilot, not to the entire development history. No scores are used to rank eligibility within a stratum. Only exposed material is included.

Freeze the exact task, complete original candidate histories, reference answers, model configuration and both prompts from the earlier open-choice and independent participation studies. All arms share the first review. The two guard arms use the same proposal to remove privately held defaults; the participant arm can veto a removal if the independent review supplies the required opposing evidence. The guard and ordinary arms share the underlying availability of this independent review in the experiment, but only the veto arm uses its outputs. Only run the independent review if an actual removal is proposed. An invalid or missing permission review follows the previous guard and remains visible. An invalid first review creates missing outcomes for all three arms. The end answer prompts contain only the final original evidence view and current task. Exactly matching Actor and Judge requests are deduplicated within the study and consume no new requests if a verified historical success exists. Exact historical unknowns and failures are retained without redelivery.

Report within-root native adapted scores, behavior, hard and soft preference protection, delivery and exact reused counts. Antecedent scores supply baselines and may not enter inference. For advancement the veto must show a confirmed correction on at least one previously uninspected task in this panel, and the complete method must produce a real net improvement over matched ordinary relevance on two independent source groups without material degradation of legitimate hard conditions, strict beneficial use or formal delivery. Closely related tasks in the same group count once. Single-draw PersistBench results remain separate from older three-draw tests. Insufficient activation or disagreements in automated grading should not be presented as successful validation. No sealed examples, no maintained memory writeback and no new training.

Use the base Python path from `evo_qamc_fit_v1/run.sh` and run `trial.py freeze`, `check`, `run` or zero-call `replay`. Caps include 21 first reviews, up to 21 requirement reviews, 63 logical Actor requests, 33 RPEval Judge positions, 18 PersistBench Judge positions and 72 BenchPreS attribute and completeness positions before deduplication. Retain the existing request journal, 3.2-second minimum interval and zero reissues.
