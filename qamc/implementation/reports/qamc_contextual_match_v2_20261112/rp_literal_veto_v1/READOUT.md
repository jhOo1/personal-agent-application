## 原文定位与边界

以 233 道已曝光任务为背景。初版命中「床上用品没办法完全不用布」中的「完全不用」，把无法执行的要求读成硬限制。修正后保留初版和复算，当前程序明确拒绝被邻近否定的见证。

| 位点筛查 | 提议 A / B / C | 原文检查后 A / B / C |
| --- | ---: | ---: |
| 窄排名 | 1 / 3 / 16 | 0 / 0 / 11 |
| 扩展排名 | 8 / 3 / 32 | 0 / 0 / 19 |

这个计数只衡量与既有作者档位的对齐。开发标签已看过。它没有证明合法强度可跨范围使用，也没有证明所有作者 C 在语义上是不可放宽的约束。

两个实际迁移失败表明应区分来源里的具体命题：

- **成都亲子行程 `implicit/013`。** 匹配到用户转述一家书店「不允许带宠物」。这是书店的规则，不能直接以其字面强度证明整个家庭路线应限制宠物。历史中另有本人婉拒猫咖或有狗家庭等相关线索，但它们不是这一条匹配的拒绝主体。新稿扩大了少宠物接触的推荐，原生 Match 仍是 6/9，UPB 2→0、OPB 1→2、FM 0→1。
- **共同餐厅 `implicit/139`。** 用户明确表示不用考虑植物，升档稿确实排除植物，却也把同一来源中的极简冷色偏好升成整间餐厅的主调。Match 仍 2/6，UPB 2→0、OPB 2→3。来源级强度把本来强度和用途不同的命题一起升级。

另有 5/16 个窄规则会提升的作者 C 在修正后没有通过可见原文检查。隐式交通与音效例中的真实限制可用拒绝行为和跨句条件表达，词面程序没有恢复它们。案例由执行者核查，无独立人工盲审。
