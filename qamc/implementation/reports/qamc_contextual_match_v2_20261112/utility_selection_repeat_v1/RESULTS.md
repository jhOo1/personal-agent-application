# 两次真实部署中，有益记忆的漏用是否重复？

比较固定 SELECTED_GEPA 在两个已结算部署中的同一批来源。第一轮有 18 个严格有益来源，第二轮有 20 个，其中 18 个与第一轮相同。按完整来源 ID 对齐全部交集，仅比较同一评分适配的严格等级 3。重复部署允许选择的原文和最终采样改变。本分析没有新模型请求，开发来源不具有独立确认资格。

|第一次 → 第二次|GPT-4.1|Qwen|
|---|---:|---:|
|通过 → 通过|18|12|
|失败 → 失败|0|2|
|失败 → 通过|0|1|
|通过 → 失败|0|1|
|通过 → 未知|0|1|
|未知 → 通过|0|1|

两次 Qwen 在这些相同来源上分别有三次确定失败，其中两根重复失败。报告完整交集，以免把三个专门核查的失败案例当作总体抽样。三个案例的 SELECTED Actor 请求哈希在两次运行中均不同。

- 桌游聚会。第一次选中了团体成员和色觉条件，漏掉主人养猫及一位参加者严重对猫过敏。第二次同时选中后两条，答案建议提前与当事人确认聚会场地。Qwen 从 2 升至 3。两次均未选中另一读书会成员的饮食限制。这是一个与恢复有用事实相符的改善，选择与生成同时变化。
- 儿童生日礼物。第二次补回孩子已有大量 LEGO 的信息，实际用它推荐了符合预算的 LEGO 星舰，Qwen 仍为 2。两次均未选中父母希望礼物能限制屏幕时间并鼓励户外活动的原文。第二次 Qwen 评语明确指出这一遗漏。请求者指定了星舰模型，家长意愿影响如何玩以及如何推荐，不能直接推成只能买户外用品。GPT 两次均判 3。
- 围栏种花。第二次补回喜欢绣球的信息，答案给出了具体的绣球选择，Qwen 仍为 2。两次均未见草花粉过敏史，却都主动推荐了观赏草。两次 Qwen 评语都指出该建议，GPT 均将过敏史视为干扰项。[逐次核验](../persist_memadapter_release_v1/GARDEN_REPEAT.md)

三题都补回了至少一条来源，只有一题翻分。生日和种花两题中的额外历史是否有用，部分取决于最终推荐的具体物品或配套行动。简单增加选中条数仍可能漏掉这一联系。下一项可证伪比较可固定同一提案，按提案中的可执行行动核查遗漏历史，对比同额的普通证据复核；先检验能否修正具体行为并保住已有正确内容。种花存在两裁判实质分歧，不能作为独立确证。以上病例已曝光，不能进入后续独立确认。两轮 Qwen 的失分重合不等于确定因果，也不能替代对强对手的最终生成评测。
