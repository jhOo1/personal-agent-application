# Is estimator disagreement a distinct source recovery operation?

On the archived 274-task complete RPEval endpoint panel, IPE-C turns history off when no IPE top prediction is C. On that branch take every item with IPE top B and MLE top C. Compare with the same number of items from the original fused RP ranking (C, then B, then A; stable original order within ties). Restore original order after selection. The selection uses only saved predictions. Author labels are joined for this offline qualification. A full-history RP answer is not an answer generated from either new subset.

The rule triggers on 24 tasks, two also included in the earlier source-local re-entry experiment. Of 29 exposed positions, disagreement selects 7 A, 19 B and 3 C versus 13 A, 13 B and 3 C. The three C positions are identical at the item level. Eleven tasks from nine source groups have genuinely different evidence sets. Disagreement introduces seven author B items and removes one B item, with a positive net B count on six tasks and no task losing net B count.

This refutes a comparative hard-constraint recovery explanation on this panel: both equal-size methods expose exactly the same C items. The remaining distinctive hypothesis is that replacing irrelevant items with supporting preferences will change a useful decision on the history-OFF branch. The earlier history-ON transfer already showed that better B exposure need not improve answers. Expansion or promotion requires an end-to-end paired result; these are source counts, not Match gains. The 13 identical subsets can share outputs only when the full Actor request is also identical. Existing full-history and empty-history endpoints remain comparators. No models were called, no grade was changed, no sealed inputs were read. The replay requires the private archived RP and endpoint records.
