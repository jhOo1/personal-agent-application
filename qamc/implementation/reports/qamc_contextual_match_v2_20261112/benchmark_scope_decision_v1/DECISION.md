# 哪些基准应当继续承担论文主张？
本次只核对已曝光结果和完整外部方法接口。以下定位是研究优先级建议，原三基准的成绩、数据边界和协议保留。

|基准|重复观察|主张边界|
|---|---|---|
|RPEval|18 个开发来源的两次完整部署，IPE-C / 清空 / 完整 RP 分别为 38/91、34/91、40/91 和 44/87、32/87、40/87。17 个完全可比来源中，无一两次都优于完整 RP。|可用来证明部分任务需要历史。完整 RP 的优势方向随部署变化。|
|BenchPreS|Strong Gate 对外部 Selectivity 在 40 个共同任务上，误用 1/132 对 13/132，适用实现 58/68 对 54/68，完整度均为 4.875。非加粗实现 35/45 对 36/45。106 对重复生成中，非加粗仍为 95/122 对 96/122。|保留为表达和交付能力检验。完整分配有缺失，使用 Qwen 适配。六个合法实现的三稿空间缺口不能解释为题目不兼容。|
|PersistBench|查询条件满足时扩大历史，在 Qwen 的 18 个严格有益开发任务上通过数从 14 到 17，完整历史 18。GPT-4.1 下三者均 18。既有 93 次风险部署没有一次因该规则而扩大暴露。|优先检验风险与效用权衡；风险切片尚不能测错开历史的代价。按原评分和适配评分分别报告。|

真实机制例：公园聚会中朋友人数被请求者平时的社交习惯限制；共同布置餐厅时过去明确的无挂画、无布艺要求仍有约束力。两种结果可以在同一任务条件策略下相容。正式信件中的简明和客观偏好，即使通过选择器也可能没有落实。切掉这一基准会使方法回避交付质量问题。

决策：保留三项，当前优先检验 PersistBench 的完整外部方法竞争。已有成绩足以停止反复修改 RPEval 仅 B 子集和 BenchPreS 两画像的提示。更换条件是基准不能识别目标行为，且存在公开、有相同推理信息权限、可复现评分并能区分该行为的替代；若证据仅限生成器对表达的执行瓶颈，可缩小论文主张，继续公开全部历史结果。

外部方法核对：DEEP-JLU/MemAdapter 固定 6b517dc90d4c7e0ebc4d2305684d45051f792cc9 的 methods/memadapter/memadapter.py 中 run_three_stage 依次从原文归纳边界、结合查询产生用法、以原文和用法生成。第一、第二阶段默认各可尝试三次。正式比较须区分已存适配与这条完整路径，披露统一单次失败合同及固定输入适配。此核对没有产生新模型成绩。

证据：公开仓库 qamc/manuscript/paper.tex 的 BenchPreS、查询范围和重复部署各节；同目录树的 external_pool_frontier_v1/READOUT.md 与 persist_query_requested_open_v1。外法源码 https://github.com/DEEP-JLU/MemAdapter/blob/6b517dc90d4c7e0ebc4d2305684d45051f792cc9/methods/memadapter/memadapter.py 。
