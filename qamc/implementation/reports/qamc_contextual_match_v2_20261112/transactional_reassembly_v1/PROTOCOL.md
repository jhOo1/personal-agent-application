# 最后一版 · 固定强底稿的事务式答复重组

共享操作作用于三种已验证底稿：RPEval 精确 IPE-C、BenchPreS 精确强 Gate、PersistBench 精确 PB_RUBRIC。不存在统一新路由的声称。复用原始任务、事实、全部冻结候选、成稿及可核验字面锚点。两臂输入同一组带字节边界的底稿片段及保护值、同语义提示、Qwen3.8-Flash、温度 0、输出上限 8192、各一次新请求。自由对照可 KEEP 或提交完整答案，事务组可 KEEP 或提交 COPY/WRITE/INSERT/DROP 的有序程序，旧单元必须全部且仅一次覆盖。区别是程序接手复制、重排和写入。四种操作均可用，允许多单元融合和跨段联合修改，允许无改动，也会报告纯生成、无原文直接复制的程序。程序不保证历史选择适用、逻辑正确或新版的语义一致。

两臂都核验相同的有限字面事实保存，来源是公共任务及事实通道中已经在原答出现、可提取的具体字面值。原私人历史、底稿自提人数和建议不固化。字面锚点存在不证明其关系未漂移。合同问题回退精确底稿并记录问题。传输失败保留缺失，不重发。同一已有完整字面答案和同评测协议精确复用，缺失没有语义分。两臂不会再让 Judge 挑稿。旧成绩是只读输入。

冻结 92 题。RPEval 24 个来源，A/仅 B/含 C 各 8；选定追踪已核实的负例和保护题，其余在前一版共同候选池中按来源散列取样。同源不重复计。BenchPreS 原共同有效 26 题、PersistBench 原共同有效 42 题，均保留全体。没有封存数据或增加样本。主指标沿用三类原协议适配。表中保留原分、缺失、保护项、共同分母，以及实际方法到达的完整面板分母。最大 184 修订、48 RPEval 评分、312 BenchPreS 属性/完整度、84 PersistBench 评分，共 628；Exact 缓存和 KEEP 减少实际请求。并发 8，继承 3.2 秒派发间隔及一分钟流错误冷却。两臂报文先共同哈希，按固定散列混合派发。

## 事前判定

- RPEval：相对同题原 IPE-C，至少两个独立来源组有受保护净收益，至少一组来自非定向抽样；全 A、仅 B、含 C Match 与 OPB、UPB、FM 要受保护。094 核查的是消除不必要人数收缩及联动调整，076/116 核查合法舒适性/送达方案和无挂画、无布艺限制是否真实执行。
- BenchPreS：非加粗 AAR 至少增加两位，两种缺口画像分别至少一处；MR 不增加，完整度不降低，权衡按同题完整分母。必须抽查压缩是否损失必要任务事实，不能用字符数代替评分。
- PersistBench：至少两个既有失败迎合来源转为有效，且无新增跨域、已有通过的迎合或严格有益使用失败。模板、犬只适配和亲属关系书章先看真实建议或论点有无变化。
- 另比较 TATR 与强自由修订。三个域主指标均不落后且至少两域有原生分及实际行为支持的增量，才认为程序重组有独立价值。缺失可能推翻整体结论时，不晋级。按原 strong Gate、RP、Selectivity、MemAdapter、PB_RUBRIC、PB_GEPA 的已有可比较原分分开补充，不能把同题历史成交当同期独立确认。
- 完成该版本后暂停现有目标，不再自动发第三次研究交流。
