# Authorized Memory Projection · exposed three-benchmark pilot

The proposal separates permission to affect a decision from permission to expose the source verbatim. A shared model call builds a task frame from the current query, context, and fixed facts, with memory excluded. A second shared call matches original candidate spans to frame slots and proposes authorized effects, facts, or abstention. The compiler verifies source spans, drops unapproved records, and distinguishes verbatim facts from derived task effects. Permission inference, completeness of original conditions, and factuality of a derived effect remain semantic judgments. This experiment tests actual exposure and terminal behavior and offers no formal privacy guarantee.

RAW and AMP share identical candidate sources, permission plans, and effect instructions. RAW receives whole admitted originals and AMP receives authorized fact spans. Both receive the approved effects. FREE sees the same task frame and those same original candidates in an independent equal-budget call and can project, summarize, abstain, and retain facts and effects without the structured compiler. All arms then receive one generation with the same original model, system message, settings, and current task. The common auxiliary user-message envelope is a new input adapter. Previous benchmark-specific Actor contracts, especially PersistBench, have no equivalent typed channel. The adapter preserves the original empty-history user payload as a literal prefix and supplies the same adapter instructions for all arms, without posing derived effects as memory records or fixed facts. Archive references use their own prior input formats and remain method-level comparators.

The pilot consists of 18 previously exposed source groups from the verified CAR archive, six per benchmark. The roster has exactly 21 tasks because three RPEval groups contain an original all-A and added-B pair. RPEval additionally has two C-containing sources and one all-A protection source. BenchPreS has six profiles, and PersistBench has two development tasks in each released evaluation category. Gold labels, task category names, historical scores, and source-group identities are offline selection and evaluation metadata. The frame sees no memory. Subsequent inference receives only current task data and visible original candidate memory. No sealed material is read. Do not replace missing tasks after observing any returned result.

The current pilot uses each benchmark's archived strong endpoint and historical grading adaptation. Report all same-task arms, final query coverage, RPEval Match, OPB, UPB and FM, BenchPreS AAR, MR, non-bold AAR and completeness, and both release and strict BU outcomes for PersistBench. Review changes to actual choices and any unintended new terms, leakage, or facts. Missing requests remain missing. No automatic retries. A malformed shared frame removes all experimental arms. A malformed authorization removes RAW and AMP. A malformed free view removes FREE. Mechanically identical Actor requests share one newly generated response.

Advance AMP only with concrete, source-grounded differences across multiple sources, no realized loss of hard conditions or task delivery, and a clear advantage over both matched controls without a main metric loss to the frozen strong references. The pilot is small and deliberately based on previously exposed cases. It cannot establish an independent performance claim. Compare the decision channel and exposure dually only after observing real benefits.
