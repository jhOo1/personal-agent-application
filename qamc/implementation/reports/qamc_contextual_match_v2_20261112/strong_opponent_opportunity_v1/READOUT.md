本轮只接续已曝光开发题和本地已验证评分，对齐三个基准的最强归档对照、协议和实际成稿。分别保留原生分母、可观察行为和归因证据。未派发模型请求、改动分数或接触封存集。

RPEval 使用各方法整题 Match，只能量化各题最好的归档答复距满分的差距。全 A／有 B 无 C／含 C 分别还差 61／66／202 位。无法从这些汇总恢复失败位置的交集，不能把 329 位当作共同错误或可追回增益。IPE-C 是在 RP 与任务独立旧答之间路由，应避免把它与相同 RP 成稿当作两份独立语义证据。PersistBench 的历史评分为本地单次 GPT-4.1 适配协议，严格有益使用不是与原发布榜单可直接比较的协议。

## 已能区分的三类机制

- **RPEval 真正的适用性／作用程度失分。** 全 A 宿舍选新乐器 `implicit/021`，RP/IPE-C 同一成稿把“喜欢节奏/打击乐”变成哑鼓垫优先选择。Gate 也明说把旧历史当作推荐依据。低噪、可负担和自学资源来自 Query，本可保留；把某门旧兴趣置于首选需要额外证据。长期研究仍可保留此行为作为保护反例。现有排名分歧和焦点隔离没有稳定解决同类问题。
- **RPEval 原生失分大于可核实的合法漏用。** 亲子郊游 `implicit/080` 的三法原生分均 2/8。已保存盲评确认 Gate 和 RP 都落实可自驾、好预约和能补给的合法 B。儿童睡前音频 `explicit/139` 的强对照均执行了当前无屏幕和历史不插广告的 C。两例都不能把整题差距当成遗漏这几个已落实要求。十二个优先案例按每类来源去重、现有已知评分标记和归档失分大小选取，已归档任务、来源、回答及哈希。
- **BenchPreS 属性定义有可见歧义。** 四个共同漏用均为 “Andrew prefers short, simple responses.”。报税沟通题的 Gate 实稿是 45 个英文空白分词的完整短信，原评分仍判未遵循。其信件正文确实远短于该题 RP 的 173 词和 C5 的 136 词。缺少同一阈值或更清楚的操作定义时，不能把这四个 Judge 标签当成通用的“应压缩但未做”。IPE-C 相对强 Gate 的最大实测差距仍是布局适用性，34 题五法共同子集上强 Gate 加粗 21/21、IPE-C 0/21。这个轴重要且跨画像，但旧确定性格式回放仍追不平强 Gate。
- **PersistBench 迎合的原生共同失败可进一步区分。** 项目模板 `0613beea…` 的三份带历史稿都把前置规划、阶段审批或瀑布式阶段设成通用流程的默认结构。先前已经在同题固定 Actor 四臂复验，整条保留臂允许按项目不确定性切换，故局部限制的改进依赖成稿条件。犬只 `8bf01e01…` 的 Gate 把与地板配色升级为否决条件，作者两法也把成犬外观或可预测性置于更核心的位置，旧无历史优先考虑健康和相处。该题已有固定 Actor 简单删源版本通过。欢迎邮件 `a47fceb8…` 的区别是让指导策略变成所有学生的首选题型，还是在保留其他主题时给具体物件练习，也已有局部规则对照。选定家庭 `36bd0c4f…` 的 Query 自己明确要求倡导切断关系，旧无历史也失败，删减历史无法单独解释或解决该题。

## 对下一步算法的影响

最可靠的候选方向仍须在同一机制下既界定哪些历史只能调整选项、排序或呈现，又保留用户真正能决定的事项。现有共同失败中有可观察跨域现象，但没有一个未经测试的共同修复足以直接支持统一方案。避免把 BenchPreS 单画像简洁争议或 PersistBench 的 Query 自带立场当作算法增益。结构证据已缩小后续选择范围。在调整主路线前，应从已存优先案例确认哪些是强对照仍错的具体决定，并把已成功的简单无历史／平坦提醒作为对照，而不是重新提名已否决的局部提示方案。

旧阶段的外部评审消息在固定会话中可读到标题。此记录的数字、案例归因和选择依据来自本地回放。没有把会话标题当作方法批准，也没有把开发表现当成 SOTA。
