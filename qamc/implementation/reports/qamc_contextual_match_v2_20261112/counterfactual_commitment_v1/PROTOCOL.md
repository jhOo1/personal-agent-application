# Counterfactual decision commitment development test

Freeze eight distinct groups per existing benchmark from the exposed 92-case archive, by deterministic hash, with RPEval stratification 3/2/3. BenchPreS uses profiles as groups. No grades or reference labels enter requests. The previously discussed examples serve as design counterexamples and may be outside this panel.

Two common calls independently build a task answer and supply up to two history-aware complete candidates. An independently configured comparison sees the task and shuffled candidate text. Candidate content can still carry historical information. A fourth history-aware ranking call reviews the same pool. Its first place and the programmed selection are read out from the same call. The programmed selection skips only reported adverse changes or omissions with checkable quoted witnesses. Unverified claims do not trigger a veto. Witness checks establish literal origin, not semantic applicability. The strong shared-information free revision has the same first three calls, model, and fourth-call cap. This design isolates the deterministic override conditional on the comparison, not the causal value of withholding original memory from the comparison.

Use archived IPE-C, Strong Gate and PB_RUBRIC as paired references. Keep original project score adapters. Report native denominators, disputed scores, actual usage, delivery failures, commit changes, and fallback. Never reissue unknown delivery. Require improvement versus both shared-information controls and the incumbent with at least two source-group improvements and no observed increase in material misuse, undue forgetting, or task incompleteness before expansion. Score-level gains driven by flagged judgments cannot pass. This panel is development only.
