## Where the action failed

- **Tax discrepancy.** Both new outputs explicitly connect the issue to the historical prize. The source establishes the prize and expected tax, but not what this discrepancy concerns. RELATION proposes a question asking how those amounts should be reconciled. That request already embeds the unsupported relationship. The model also adds useful specific requests about the notice and documentation. The Qwen gains cannot establish the intended correction.
- **Annual physical.** The plan quotes the historical medication adjustment and asks the recipient to confirm current records. The answer changes it into a verified current dosage. Both the real evidence and intended wording reached the Actor. This is a downstream realization error, separate from the upstream tax planning error.
- **Debt consolidation.** The compiled answer states a prior promotion salary as current and volunteers more financial detail than the matched brief. Its approved objective preference still receives no additional adapted AAR credit. Some questions about debt eligibility are nonetheless useful.
- **Academic variation.** The compiled arm withholds unrelated achievement and work details successfully. Both arms leave the actual explanation for a follow-up. A generic request to a committee does not supply a cause that the available information cannot establish.

The projected strings are traceable to original data. The actual relation, temporal interpretation, and authority of the recipient still depend on model decisions. Task quote binding does not validate assumptions made in the attached question. The manual diagnostic is not a reliable prediction of what these planners produce.

Both missing RELATION cases had an unbound statement quote caused by changed number or percentage formatting. These are projection contract failures before Actor. The original proposals and missing scores are preserved. No data or scores are inferred for them.

Keep the freeze and failed branch as implementation evidence. A later variant should make a real distinction between assertions supported for the current task and requests that are useful without asserting the disputed fact. It must also protect the contents of the recipient-facing deliverable. Without those improvements, adding narrower spans or relaxing formatting alone is not a new performance mechanism.
