# Demand-conditioned MemGate coverage preflight

This phase emits task information needs and computes the actual learned score matrix. It does not generate or score final answers. Read the exact original 12 exposed beneficial-use tasks and the two existing project risk probes (reusable project template and kickoff email) from the matched Actor panels. These are design-exposed development sources. The two risk probes are never used to choose a setting. Existing answers, original scoring, releases and sealed inventory remain unchanged.

Each task receives one Qwen3.8-flash deterministic-settings need proposal from the current query alone. The original memory is withheld at this stage. At most four open needs can be stated. The subsequent local scorer combines each need with the original query and applies the released MemGate network to the same ordered original candidates. Include the original unchanged query as row zero. Use the same original gate threshold 0.07 and exact per-task cardinality K of MemGate's unmodified gate. K=0 remains empty. Do not tune score thresholds on these cases.

Both proposed arms consume the exact same matrix. U takes the top K by the maximum clipped excess above 0.07 across rows, with original score then source order as ties. C maximizes the sum of per-row clipped maxima for a size-K set, with total original score then original order as ties. For these small fixed pools use exact enumeration. Return selected indices in original input order. Scores are not calibrated applicability probabilities.

In the evaluation layer, check full necessity sets from already exposed cases: special dinner needs the shellfish restriction, the hosts' diet and the other guest's seafood restriction; pet food needs the named pet identity plus the documented dietary restriction; book club jointly needs the guest allergy and guest diet. Validate the original source spans against the stable task data before dispatch. At least two distinct unmet roots must recover all their specified necessary records in U or C before considering final answers. The project probes test re-exposure of known task-inapplicable private process preferences and are reported alongside BU. A gain that only U generates does not justify running a C-specific main claim. If there are insufficient recovered cases, settle this frozen design without rephrasing or lowering the threshold.

Any later end-to-end test needs an actual common GEPA Actor and grading protocol, paired ordinary strong selection and selection-by-maximum comparisons, live behavioral safeguards, and preserved old scores. A different selected set or an optimized internal objective is not a final outcome.
