# Task-supported shared defaults on a strong Actor

Counterfactual pruning failed to change two shared decisions when other history expressed the same preference. This pilot keeps the original strong Actor's full input and tests whether asking it to construct a shared default from task evidence before applying history changes the actual decision. An exception covers an applicable binding constraint of an affected participant, even if it was only expressed in history. A structurally independent personal choice may coexist without setting a new common default. No extra model stage, gold label, case-specific rule, or programmatic claim of guaranteed isolation. This deliberately measures the value of a specific first-generation instruction before implementing another representation or compiler.

The equal-call DIRECT control provides a strong, explicit scope and quality reminder. Both arms append one instruction to the same archived system message. Both retain historical policy and literally identical user messages, sources, model and sampling parameters. The archived IPE-C endpoint is a further historical comparator. The scope instruction is not the same as the prior draft-edit map, self-reported polarity gate, or record deletion, but the contrast does not isolate ordering from the rest of the instruction.

Freeze six already exposed RPEval roots on the exact archived history path. The picnic, children's room and dinner look for misuse of a personal preference as a shared default. The dining-room, living-room and takeout cases protect no wall art/fabric, a verified participant requirement and seafood exclusion, respectively. Keep all six assigned cases and report common valid results and missingness. Stop unless the new arm shows at least two desirable changes on distinct risk roots, no loss of known hard requirements and positive paired Match against both controls, without increasing aggregate UPB or FM. Any passing result is a development screening signal. No new external scores, sealed access or benchmark replacement in this pilot.
