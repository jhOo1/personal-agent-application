# Frozen reward runtime

Use `settlement/local_resume.sh` from this directory in the restored private project. Point `QAMC_REWARD_SNAPSHOT` to a folder named `853c9e6e0f71862785dd0b8eefca9609f8e720cb` containing all eight safetensor shards, configuration, pinned author code and tokenizer. Point `QAMC_REWARD_PYTHON` to a Python 3.12 environment with PyTorch 2.14.1, Transformers 4.41.2, Accelerate 1.16.0, Tokenizers 0.19.1, SentencePiece 0.2.3, einops 0.8.2, safetensors and Hugging Face Hub 0.36.2. Use a Metal-capable host for this launcher.

Before inference on benchmark answers, CPU smoke tests verified the 227-parameter/buffer checkpoint inventory and author tokenizer, and checked batched against individually called reward scores on synthetic texts using a small random instance. A second synthetic smoke checked the completed CPU and Metal forward paths. An official half-precision shard layer was then tested on synthetic tensors. CPU required 7.4 s for one layer at three 640-position inputs. The warmed Metal layer with offloading required 0.4 s in the local probe. This preflight did not grade any real candidate. It motivated using Metal layer streaming before the first benchmark reward choice.

All eight unquantized author weight files use the same model revision. For a host with 16 GiB of unified memory, the backend uses Accelerate to stream one layer at a time. It keeps the author's tokenizer, FP16 checkpoint, per-answer reward head and per-task three-conversation batch. CPU and Metal can have distinct floating-point rounding. The wrapper records a separate device and runtime fingerprint, checks the pinned score implementation, prohibits concurrent writers and resumes only uncomputed reward panels.

The SDK or author mirror can transfer shards. For any mirror transfer, match the full SHA-256 to the same pinned Hugging Face release before linking it into the snapshot. Do not mix revisions. End-to-end execution is offline once files are present. Neither the public archive nor its Git checkout supplies the original answer packets.
