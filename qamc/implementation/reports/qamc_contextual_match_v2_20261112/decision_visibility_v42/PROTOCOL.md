# V42 冻结开发协议

## 样本与对照

全部 233 道 V41 开发题、43 个来源组及既有波次、118 道较少直接曝光的子集不变。仅使用已有公开开发输入。标签、评价理由和答案均不进选择器或 Actor。两种选择器的原文、顺序、任务和输出合同一致。三条新臂使用相同 Qwen Actor 与作用范围合同，实际进入 Actor 的原文按对应条件编译。

| 处理 | 选择器 | Actor 可见原文 |
|---|---|---|
| DIRECT_MASKED | 强普通适用性 | 已许可来源 |
| SCOPED_FULL | 从现有决定和受益人检验用途 | 全部来源，未许可标 A |
| SCOPED_MASKED | 与 SCOPED_FULL 共享同一次选择结果 | 已许可来源 |

主对照为 SCOPED_MASKED 对 DIRECT_MASKED，隔离适用性设计。SCOPED_MASKED 对 SCOPED_FULL 是同一预测的可见性消融。归档强 Gate 和 RP-Reasoner 作为整套方法对照，Actor 提示与推理成本差另报。没有额外的逐题手配规则。保留完整原文及其条件，因此同一保留源中的其他内容依然可见。

## 执行

Selector 和 Actor 走 qwen3.8-flash，温度 0，输出上限分别为 8,192 和 4,096。结果用既有作者 rubric 的 GPT-4.1 同配置评分，温度 0、输出上限 8,192。用物理请求哈希跨臂与跨波次复用，包括已保存的空历史草稿和对应 Judge。交付未知的原请求按同一哈希继续保留。失败不改写为拒绝全部历史，也不按同一请求重发。并发至多 8、最小间隔 3.2 秒，网关流错误冷却 60 秒。

分阶段名义物理上限为 466 条 Selector、699 条 Actor、699 条 Judge。第一波 4 个冻结根用于运行和评分合同验收。至少两道同时取得三臂有效 Match 后自动继续剩余面板，首波仍属于开发结果。

## 晋级判断

最终宽面板报告配对原生 Match、来源组重采样和留组敏感性、全 A 和含 B/C 分层、OPB、UPB、FM、选择强度、可见性、缺失上下界和实际成本。较少曝光与其余来源分别报告。强普通筛选和同预测可见性消融分别解释。

进入跨基准正式开发比较须同时满足这些条件。相对同预算强普通筛选和归档 RP 的配对 Match 点差至少 +3 pp，且其来源组 95% 区间下界为正。对强 Gate 的配对点差为正。相对同预算强普通筛选，混合任务的原生 Match 下界不低于 −3 pp，平均 UPB、FM 各最多增加 0.1。核对受益人、软偏好与硬约束的真实成稿行为；经核验的普遍漏用、任务不完整或错误归属可否决晋级。原生分争议保留，独立行为质量未取得时只报告数字筛查，仍需核验。可见性消融若无增量，单列结论，不能把任何整体分差归因于遮蔽。

此轮不使用封存来源。开发分和三基准结构验收不能证明 SOTA。BenchPreS 与 PersistBench 的同协议强对手和保护项须在后续端到端结果中单独成立。
