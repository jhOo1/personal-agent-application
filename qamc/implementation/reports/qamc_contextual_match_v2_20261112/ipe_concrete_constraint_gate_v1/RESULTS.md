## 实际错误位置

- **韩语速成 `implicit/115` 与 `implicit/117`。** 两道题共享同一份任务答复。其历史分别呈现对注册的反感及偏好阅读、常跳过视频等表达。原稿给婚礼句型、词典查询和跟读路径，没有核实入口是否免注册，也没有明确要求用视频。程序强调找出已经推荐且可证冲突的动作，无法凭此补写资源筛选条件或更合适的学习形式。两题都有漏用评分，但同属一个来源组。
- **青岛家庭游 `implicit/148`。** 历史表达对购物占据自由时间的反感，原稿仍在步行街段安排买伴手礼。两组均未提出修订。可以核对它确实推荐购物，但从历史不能直接推出全家不能去带小吃的步行街。需要区分影响游览主线的安排与允许个体自选的活动。
- **健康外卖 `explicit/006`。** IPE-C 已明确选择非海鲜蛋白、排除相关汤底和调料，且给出省时外卖模板。普通组仍选出海鲜限制和省时要求并重写，Match 4/6→3/6、OPB 1→3。见证版复用原稿。
- **野餐 `implicit/094`。** 普通组把个人选择僻静咖啡馆的习惯当成野餐和桌游的限制。见证版没有加这个条件，但 IPE-C 原稿已经偏向安静的小团体。两组仍 0/4，不能用保持原稿解释为修好了全 A。

## 下一步范围

已存 282 道有效 IPE-C 开发题共有 1,510 个 Match 位置。115 道含作者 C，只有 3 道在有效无史路径，对应 2 个独立来源。即使将这 3 道由 6/13 改成 13/13，也只增加 7 位，约 0.46 个百分点。这个上界只约束专修该分支的收益。它不约束有史但未落实限制、误用 A、合法 B 增量或其他基准上的空间。后续应分别定位有史成稿的真实失分，避免将每个作者 C 都当成措辞明确的全局禁令。保留 IPE-C、Strong Gate 和 PersistBench 现有参照，不扩大当前见证提示。

24 次实际模型请求均成功，包括 20 个选择、2 个新 Actor、2 个评分；报告 87,791 Token，无未知用量或重发。普通组一次合同失败另计。两道任务的原始输入从已曝光正式面板按请求摘要补齐，首次预检未找到记录时没有派发请求。旧分和封存不变。
