# Repair an observable hard-constraint conflict using only relevant source text

Compare general hard-constraint selection and witnessed conflict. Both see the same
current task, original history and exact archived IPE-C answer. Both return the same
contract: zero to two original sources and exact complete constraint excerpts.
Witnessed conflict additionally requires a distinct exact excerpt of an action in
the existing answer that would violate the named condition. The program verifies the
declared source and literal alignment. It does not verify semantic incompatibility.
Ignore private wishes that affect someone else's choices and avoid turning a flexible
historical preference into a constraint.

An explicit empty output retains the same archived answer and grade. On a nonempty
valid selection, both arms run the same fresh answer model from the original task.
It sees only the chosen original sources and exact constraint excerpts. It does not
see the old answer, prior evidence policy, ratings, witness text or reference answers.
A bad return or transport failure is missing and never silently falls back. Compare
same-task adapted Match, OPB, UPB and FM separately. Duplicate wires share their reply.

Freeze the 3 previously exposed author-C tasks on the valid IPE-C task-only route,
3 history-on hard cases with already inspected concrete protections (takeout, furnished
room and a trip), and 4 previously exposed all-A protection cases from group decisions
and study resources. The archived selection is outcome-enriched diagnosis; author
strata are used to define the test roster and evaluate, not passed to any model.
The title "witness" certifies only character provenance. A genuine lift needs at least
two different source roots with both matched score and actual supported action improved
relative to ordinary selection and original IPE-C, and no new confirmed A misuse or
lost legitimate constraint. New requests are capped at 20 selectors, 20 Actors and 20
evaluations. No sealed use, request retries or edits to old artifacts.
