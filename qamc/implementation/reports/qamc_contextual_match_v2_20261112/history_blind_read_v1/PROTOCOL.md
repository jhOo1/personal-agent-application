# Does explicit history bias the reading of a complete answer?
Freeze twelve exposed development groups from the DREW archive. Reuse distinct complete candidates in deterministic anonymous order with the original strong default. Select four different groups per benchmark without ranking by scores. Include the already diagnosed picnic and joint interior-design cases, a B-only case, the project template, dog selection, cross-domain and beneficial-use cases. Fill remaining places by UID hash. These diagnostic anchors are exposed; do not infer population prevalence. Retain any missing archived score.

Both arms first read the same task, current context, facts and full candidate text. Only FullRead also sees explicit original history at that step. The second call gets the entire task and history, candidates, default and the first reading under an identical prompt. The readings may infer history from the answers. A source quote validates text provenance only. Use the original strong default on invalid reading or decision, recording the reason. Report these fallbacks separately. No Judge or new candidate calls. Compare original frozen scores, per benchmark and with behavioral regressions. This pilot cannot establish a positive effect if cases switch only because the other arm fails to parse.
