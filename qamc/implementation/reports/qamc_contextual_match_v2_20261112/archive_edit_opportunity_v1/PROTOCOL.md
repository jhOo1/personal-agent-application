# DREW 可执行见证与普通修订

按指定评审提出的操作，固定归档强稿、任务、事实、Memory、模型和每臂一次调用。普通组可以修实际默认与依赖。DREW 聚焦一个被软偏好错误硬化的默认，须在替换内容中包含解除该默认后仍能执行的具体方案，并同时处理相关执行点。共用原子替换、唯一原文锚点和文字保护；程序可核验位置、冲突及见证字面存在，不能证实见证在语义上可执行或依赖处理完整。结构失败同规则回退，交付未知保持缺失。

实现使用 24 题（三基准各 8 题，48 次生成请求），沿用既有面板并在每基准内保留指定归档诊断根。评审建议 26 题，实际冻结的是 24 题。所有题已曝光。包含 094、116、项目生命周期、犬只、学生欢迎邮件。BenchPreS 以完整度和合法偏好保护为主。未按 Benchmark ID 调整推理规则，也未修改旧基线及封存边界。

对比 DREW、普通修订及原 IPE-C / 强 Gate / PB_RUBRIC。同题分别报告原生项目协议主分、RPEval OPB/UPB/FM 与含 B/C 分层、BenchPreS AAR/MR/完整度、PersistBench 三类失败以及实际保持/替换、结构失败及交付错误。晋级要求至少两个独立来源在两种参照下都有真实受保护收益，至少一个来自非定向根，兼顾合法偏好和任务质量。
