This produces a conditional 34-task allocation, including 29 outside the preceding answer trial, selected without author labels or old performance. All originally empty, full or untriggered tasks are identical by construction. No newly scored outcome will be used to select among the arms. Previous development is exposed; this is not a new independent confirmation dataset.

The two expanded arms use the same additional one-record budget on the same tasks. The stronger fused ranks and English score only break selection ties as already frozen. No stages force word usage or revise the actual answer. Old IPE-C/RP scores are read-only same-task context references. Report task and source-group dependence, feasibility severity and applicability errors, the earlier 24-task overlap and the other exposed tasks separately, the all-A slice, actual source character counts and input usage. Cases of legitimate preference degradation are not offset by a better aggregate Match. Admit that rank agreement can mistake relevance and dominance, especially across role boundaries.

Reuse exact previous English, original Chinese gate and RP endpoints before checking the broader non-sealed cache. Match inputs by complete SHA-256 and validate stored replies and grades. Retain missing or failed exact receipts, never substitute a better draft. Share one physical sample for identical new contracts. No new selector calls; the deterministic slot acts on predictions already required by the shared RP policy. At most 102 Actor and 102 Judge calls before cache and deduplication. Exact preflight may reduce the ceiling. Actor and scoring model aliases and adapted RPEval rubric are unchanged. Preserve latency, costs, raw research traces and source provenance privately. Do not run other branches while this trial is active. Loss of feasible actions, increased misuse or absence of benefit beyond Top-next is evidence against advancing this method.

This is the zero-new-selector-cost falsifiable first pass. An ordinary language-model reviewer with the same one-slot permission would be an additional, higher-cost comparison if this fixed rank-based primitive has a genuine signal; the current equal-expansion Top-next arm alone does not establish superiority to all ordinary reviewers.
