# A frozen one-slot addition retrieves constraints that gate ranking misses

Across 286 bilingual exposed RPEval development contracts, infer an optional source using only the archived IPE ranking, MLE ranking, original fused policy and English MemGate scores. Preserve every gate-selected record. The counterpart adds the next English-scored record on the exact same triggers. Outputs were saved and hashed before accessing author labels for this diagnostic. This rule was conceived after inspecting the previous 24-task trial and cannot count as an independent prospective study.

Among changed tasks, 13 of 16 conservative source groups gain a net applicable position and none loses one, with 11 such groups outside the previous trial. This is a source selection result and does not measure use in the final answer. Sixty-five initially empty gates remain empty. The outcome cannot excuse the two additions on all-A tasks. One upgrades a living-room-style discussion to the child's room and the other interprets an old preference for cool colors as required when asking for ideas for a cozy living room. Rank agreement does not resolve beneficiary and decision authority.

The omitted sources for the white-noise restriction and the no-spice dinner are both restored by reservation and missed by Top-next. These cases are useful regression probes, not independently discovered wins. Test actual source usage and answer quality against both the original English gate and Top-next.

The answer contrast freezes all 34 triggered tasks from 21 source groups, with no selection by scores or author labels. Ninety unique Actor wires collapse 102 logical outputs. Six verified old Actor/scoring paths are reused. Up to 84 new actors and 84 grades remain. The live stage can only use the private pinned plan and then fixes the scoring response cache before dispatch. Twenty-two tasks have genuinely different expansion wires. No new cloud call was made for qualification, and sources from the reserve are excluded.
