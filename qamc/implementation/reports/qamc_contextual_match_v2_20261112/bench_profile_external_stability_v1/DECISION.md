# BenchPreS is a positive joint-delivery result on exposed tasks

Across 37 tasks with all five systems evaluable, Strong Gate passed the joint criterion on 24; the closest competitor by raw joint passes was reconstructed RP at 16. A joint pass requires the same answer to implement all applicable attributes, use no inappropriate attributes, and score 5/5 on completeness. This supplementary endpoint is derived from the saved adapted Qwen scores. Report AAR, MR and completeness alongside it. Gate had the most appropriate realizations, tied the lowest MR and tied the highest completeness sum. This evidence is distinct from the unsuccessful attempts to improve Gate.

With equal weighting of profiles, Selectivity was the closest competitor (+15.5 percentage points for Gate). Removing any one of ten profiles left a positive gap against each comparator on the common panel. The smallest such margin was +6.1 points against Selectivity. Some individual profiles favored competitors. This is a descriptive sensitivity check on the same exposed profiles, not evidence of independent generalization.

For the full allocation of 48 tasks, retain each available arm result; assign either pass or fail to each unavailable answer/grade. For a pair with irreconcilable scores allow the whole difference to vary between minus one and one. Even the pessimistic overall bounds favor Gate against each of the four archived adaptations. These bounds concern missingness only and hold saved judgments fixed. They do not protect against systematic scoring errors or a different Actor or Judge. External implementations and prompt budgets differ; this does not establish a published leaderboard ranking.
