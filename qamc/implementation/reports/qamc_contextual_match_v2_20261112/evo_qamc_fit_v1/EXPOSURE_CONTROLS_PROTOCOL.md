# Matched Scope Actor exposure controls

Freeze this comparison before any new grade. Retain all 162 exposed development assignments and the earlier batch order. Two assignments have no successful Scope Actor and stay unavailable. In the other 160, the original no-history planning receipt is verified against the plan string in the original Scope Actor request. Freeze the model alias, service reference, system message, task and facts, plan and output settings. Only the original history list changes.

| Outcome | What reaches the frozen Actor |
|---|---|
| OFF | An empty list of historical sources |
| SELECTED | The original selected sources, with exact cached Scope answers and grades |
| FULL | All frozen original sources in their existing order |
| GATE | A single ordinary controller predicts OFF, SELECTED or FULL before reading any new end answers or judge scores. The delivered answer is precisely that endpoint. |

The controller sees the task, its plan, the original sources and selected IDs, with no author relevance labels, grades, benchmark names, or routing history. The controller's inputs never enter the downstream Actor. An invalid controller response has no selected endpoint. Preserve unknown transport states, missing scores and the complete assigned denominator. Do not reissue exact failed requests. Exact Actor successes from the earlier expansion or earlier control batches are reusable. Identical Scope answer and case reuse their existing grade, including an existing missing grade.

Then execute one exposure batch at a time. Candidate generation and grades cannot change a gated decision.
