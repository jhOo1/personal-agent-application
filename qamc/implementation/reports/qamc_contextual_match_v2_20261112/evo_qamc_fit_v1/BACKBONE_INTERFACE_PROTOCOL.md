# Model × interface × memory exposure

The next test separates model substitution from the effect of the actual answer-generation interface. The no-history negative controls showed that a new Actor can change RPEval overuse scores without any supplied history to use. The fitted whole-prompt search did not establish a new method. This experiment reuses two earlier, complete shared interfaces and crosses them with a model alias and actual history availability.

| Factor | Frozen values |
|---|---|
| Generation alias | qwen3.8-flash, deepseek-v4.1-flash |
| Existing interface | Scope with the exact task-only plan, Self-ReCheck Direct with no plan and its existing system instruction |
| Evidence | Exact ordered Self-ReCheck subset, empty evidence |
| Fixed | Task, facts, original memories, temperature 0, maximum 8,192 tokens per generated answer, scoring contracts |

No new selection, planning, or feedback optimization. The two interfaces differ in both plan availability and system instruction; an interface effect cannot be assigned to the plan alone. A model alias is not weight attestation. Identical output caps do not imply equal hidden computation. No non-thinking request override is used.
