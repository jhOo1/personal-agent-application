# Can task computation replace raw context?

The proposed operation would use a private source to filter existing options through a deterministic, grounded predicate, without releasing the original value to the final Actor. It differs from an LLM-written conditional paraphrase only when all operands and options already exist and the program actually performs the computation.

## Frozen one-root intervention

Use the exact archived DeepSeek Direct with selected history that wrote the private scheduling details. This is an exposed, outcome-selected diagnostic for the observed behavior, not a deployment policy or a new backbone sweep. Register the one already reviewed answer path and two whole Fact occurrences locally. Freeze a new request that removes only those two entries. Keep the original model/service, temperature, cap, system prompt, query, all other Facts and selected history. The original Direct has no plan. All control scores and source records remain intact. Maximum one new Actor and six inherited attribute/completeness graders; no resend of delivery-unknown.

The pre-scoring behavior check is whether the final message keeps a concrete accommodation request and appropriate emphasis, while ceasing to cite the private schedule. Also check that it does not invent an alternative time, reveal the same schedule through another channel, or drop required delivery. If the message is no longer useful, report a tradeoff. Equal or better adapted BenchPreS counts would be secondary; the project attribute labels do not directly measure private schedule disclosure. A change in one new draw cannot rule out generation variation. No number from this probe should select a new policy or estimate behavior frequency.
