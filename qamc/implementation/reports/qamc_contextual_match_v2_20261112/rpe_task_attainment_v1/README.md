# RPEval 每道任务满足多少偏好位置

冻结 300 道已曝光多偏好题。仅在三个端点均有严格 Match 的 274 题上，把每题的匹配数除以该题的位置数，逐个有理数门槛统计达标题数，每题一票。无已知争议标记的共同子集有 184 题。RESULTS.json 保留全部观测门槛以及 1/2、3/4、9/10。此次为事后诊断，不用门槛选方法、不替换主评分。0 新请求。

|同题范围及门槛|IPE-C|始终不用历史|完整 RP 重建|
|---|---:|---:|---:|
|274 题，至少半数位置匹配|220|171|196|
|274 题，至少四分之三|104|107|76|
|274 题，所有位置匹配|95|103|64|
|184 题，至少半数位置匹配|151|119|128|
|184 题，至少四分之三|85|90|62|
|184 题，所有位置匹配|81|90|58|

与无历史相比，路由的收益集中在部分完成。提高要求到四分之三时，净优势已消失。与完整 RP 相比，两种面板在上述三个门槛均领先。位置来自项目冻结 Judge；这项诊断不证明整道任务客观完成或儿童、饮食等特定硬约束必然得到落实。未来报告保留原逐位 Match 和整题全对并列，不以事后门槛作为胜负标准。

输入为原研究仓库同级 ipe_c_two_endpoint_completion_v1/RESULTS.json。运行 python3 replay.py 可复算，公开仓库仅含算法及聚合输出。
