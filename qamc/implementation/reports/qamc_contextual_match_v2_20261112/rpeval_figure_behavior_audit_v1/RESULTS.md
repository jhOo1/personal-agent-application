# What the Figure 14 rank reversal tracks on fixed answers

The no-history Actor envelope and scored reply were reattached to the same archived receipts on all four author all-ignore cases, with no original source, memory policy, or fixed fact records. The task and current context were unchanged. All four selected IPE-C's no-history endpoint. Under the explicit Figure 14 format control, all four received UPB 5. Three of the four explanations explicitly call the answer generic or say it integrated no prior preferences, then assign severe underpersonalization. The fourth associates quiet route options with private preference use and nevertheless describes that as underpersonalization. These reasons cannot substantiate omission of an applicable preference under the all-ignore labels. The diagnostic is an implementation check of this grader, not a claim that these are wrong grades from the authors' original run.

The masked Qwen reader received full reference history and the current task with each answer. It did not see method identity, answer exposure, author labels or the prior scores. Every asserted trace quote matched the reviewed answer. The reader still assigned four apparent soft uses to the all-ignore no-history answers. Inspecting those traces, they reflect generic decluttering and a reading corner in a living-room proposal, quiet music guidance in a home-party proposal, and a quiet-route option conditioned on the parents' wishes. The labels detect surface alignment, and the archived requests rule out these four outcomes being caused by explicit memory exposure. They do not prove the suggestions are inherently inappropriate. This is why soft-implementation labels from a reader that sees history cannot substitute for input lineage or a controlled intervention.

In one C control, the full-history answer explicitly excludes outdoor eating and gives an indoor tabletop plan. The memory-free answer allows a picnic. This is an observed feasible-action difference on a real request. The second control does not establish that full history always realizes the dominant preference. Preserve both: the benchmark has actual utility trade-offs and also an attribution problem in this scorer.

All 32 positions were determinate and paired on this small panel. Twelve behavior-review requests returned successfully, 85,890 reported tokens, no unknown usage or retries. No new Actor outputs or original grades. The separate operator reading knew the previous context and is not an independent human blind review. Zero independent human reviewers. Read-only replay reproduced the settlement; the replay fix compares canonical JSON so Python tuples and their stored list representation do not produce a false mismatch. It does not change a request or grade.

**Decision.** Keep the original detailed project score plus explicitly labeled sensitivity and behavior analyses. Do not use the Figure 14 crossover or the Qwen reader as a replacement leaderboard. Stable gains should be sought on concrete preference realization with traceable task fit for both inappropriate and applicable histories, not by optimizing against the malformed all-ignore severity signal.
