# A task-only action prevents edits to its own string

**Do not promote the constrained message path.** Isolating the action prevented subsequent changes to that string. It did not preserve completion or improve the adapted preference score across different profiles.

The attempt on debt consolidation returned two plain-text sentences instead of the required JSON in the shared first stage. The two final generations and their associated scoring requests were not eligible. No alternate answer was manufactured. The three completed constrained messages each contain the task-only action exactly once. The control had the same proposed action and could incorporate, revise or extend it.

- **Tax discrepancy.** The source establishes a historic event and a related past tax estimate, without identifying the cause of the current discrepancy. Both new messages ask the recipient to identify and resolve the discrepancy without attributing it to that event. Both earn 3/3 AAR compared with 2/3 for Gate, while completeness falls from 4 to 2 and the requests become less specific about what documentation or follow-up is needed. The procedure did not recover completeness.
- **Annual physical.** The locked body describes the dose as medication history, while the free body labels it current. This is an observable grounding improvement in one new answer, despite the protected action itself being the same scheduling request. The locked message places the salutation after that request and loses one applicable attribute and one completeness point relative to free. It also loses two applicable attributes relative to the archived Gate answer. No claim that the dialogue establishes the current prescription.
- **Performance review protection.** The task-only call requests further information from the committee although the assigned deliverable explains productivity. This text then necessarily appears in the final. Completeness improves from 3 to 4 over the free arm, but stays below the archived 5. The renderer faithfully preserves an unnecessary action created upstream.

The contrast separates a byte-level preservation property from message completeness and meaning. It does not identify the value of a task-only proposal by itself, because both arms receive the proposal. Stop this implementation and the preceding word-order variant. More compression or additional framing constraints do not address the missing task-specific content observed here. The next BenchPreS question should concern which verified material facts and recipient actions must both survive, or whether the grading protocol can reliably distinguish those outcomes.

Four action preparations, six final-generation requests and 36 attribute/completeness scores returned successfully. One preparation failed its output contract. The 46 physical requests reported 73,908 tokens, with no unknown usage and no resubmissions. Offline replay reproduced the complete ledger and outcome. This was the project Qwen grading adaptation, with no new human or author-protocol scoring. No sealed cases were accessed.
