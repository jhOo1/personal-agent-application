# One-pass decision edits on RPEval

Use the fixed 24 exposed single-preference tasks and the exact selected V1 draft for each task. Compare a single general editor with an editor that emits executable decision changes. Both arms see the raw memory, task context, fixed facts, lossless draft index, and the two other complete solutions. The default answer has already been selected by the historical V1 method with no access to grades. No V1 or candidate generation is repeated. The API service, Qwen backbone, temperature, output cap and paper-derived detailed single-item scoring adapter are shared.

The index distinguishes original list items, prose and fixed format units. The boundaries reflect text structure and cannot establish semantic independence. V2.1 combines locating and producing edits in the same request. FREE can write a complete answer or keep the draft. DELTA can keep or make up to two independent groups, covering at most three original units and 60% of the original nonblank content by unit length. Outside the chosen groups the exact original bytes and order are retained. Invalid edits fail their group. Two valid groups targeting the same unit invalidate the plan. Related edits within a group commit together. A local size limit bounds new text.

OFFER must extend a concrete option in an existing list item when the draft has list items. It retains that item's original text. Without list markup, it extends a selected prose unit. TRIM can remove a unit. QUALIFY and ALIGN can replace or extend affected units. A visible task or history quotation is required for each group. Binding a quotation proves its origin only. Whether it justifies the decision is evaluated from the actual answer. There are no task examples, labels or prior scores in the model input.

This design tests the whole one-pass constrained editor against a one-pass FREE editor with identical evidence. It does not isolate the contribution of the index, accepted actions, bind checks, or shared prompt. In contrast with the two-pass shared locator trial, both arms can attempt every assigned task and individually decide whether to intervene. Start from V1 in both arms so a measured net gain means adding to an existing effective answer policy. The previous RP-based experiment is historical context, with different starting drafts and inference budgets.

Primary measurement is paired Match on the prespecified historical 22-task overlap, with valid counts per arm, the all-24 allocation, and worst and best Match deltas for missing scores. Also report OPB, UPB, FM, and A/B/C outcomes, recoveries, regressions and net difference from V1. Discuss serious losses of explicit requirements independently from ordinary score differences. A clear action difference supported by the actual answer and favorable net performance against V1 and FREE motivate development expansion. Aggregate ties and completed missing outcomes cannot substitute for those observations.

Maximum 48 generation and 48 scoring requests. The two arms dispatch in a deterministic interleaved order. Delivery-unknown attempts remain missing. Keep, failed format and invalid groups that leave the draft intact use a grade bound to the exact draft. Archive all original results. The answer inventory must be locked before new grading. Access only the prior exposed development roster.

The public archive contains the method and protocol. The executable experiment requires the restored private QAMC checkout and frozen RPEval artifacts from [the parent comparison](../rpe_protected_repair_v2/RECOVERY.md).
