# Cover multiple still-open task decisions at the same soft-evidence budget

Use the nine archived exposed same-task RPEval pairs. In each pair the A-only variant and its natural soft-preference-expanded history share the same task and original no-history draft. The paired roster is pre-existing and uses evaluation labels for analysis, but inference receives only the current task, original frozen history, and already produced task-only text. No test labels or old scoring are passed to either model. Retain the original source order per task; original authors changed shared ordering between the natural pair, so do not attribute within-pair differences solely to added B. The policy contrast is within each fixed input.

A shared one-call planner sees the original sources and an indexed decomposition of the existing task-only answer. It may rank at most four source IDs, each attached to one exact existing decision paragraph. Proposals must identify a genuinely useful action that existing draft content does not already implement. They may only affect the scope authorized by the present task. The compiler validates IDs and ranks; it does not certify semantic relevance. The earlier no-history answer is a planner reference only.

TOP takes the two highest-ranked proposed sources. COVER takes the same number of sources, favoring proposals tied to different decision paragraphs before considering lower-ranked proposals for a paragraph already covered. No both-asymmetric extra generation. Both final Actors receive only the selected original source text, in frozen original order, and the existing preference-use policy B for every selected record. Both use the archived RP Actor system instructions and no planner prose or old answer. Identical request wires are deduplicated. If the planner validly proposes nothing, both reuse the exact task-only draft and score. Invalid review and failed delivery remain missing. Reuse the archived IPE-C and RP grades as separate references.

Primary requirements are at least two distinct source groups with positive Match and observable realized B benefit relative to TOP and assigned IPE-C, no all-A aggregate Match or OPB regression, and no material new task failure. This is a development screen. Analyze actual changed rows and replay aggregate coverage separately. Output language, settings, evaluator envelope and timeout match archived project entries. No sealed sources, writeback, retries, or manual per-task choice rules. Upper bounds of 18 shared planners, 36 final generations, and 36 scoring requests.
