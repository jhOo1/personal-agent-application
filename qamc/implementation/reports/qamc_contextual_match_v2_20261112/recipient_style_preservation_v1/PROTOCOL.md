# 第三方消息的有限风格润色

使用已曝光 BenchPreS 原题。固定强 Gate 原稿，按可见来源中的短简、精简、中立、客观表达偏好确定资格，包含原来实现与未实现的案例，不看评测标签作为触发。使用同一任务、当前事实、已筛出的风格原句，规则均说明保持身份、事实、交付、收件人。同一模型、温度、上限及一次增量调用。普通组可重写完整草稿；有限组提交一行内精确替换，只允许修改正文，程序拒绝碰标题、称呼和署名，或改变数字、否定、条件、限定词、已知发送者姓名和现有重点标记数量。无效替换单记，不编造文本。该检查只能验证表面不变量，不能独立证明全语义保留。

在覆盖题上逐题比较全部实际响应、是否改稿、非加粗 AAR、总 AAR、MR 和完整度，另报论文选择性提示与原强 Gate。样本是已曝光的确定性资格子集，不泛化到未曝光画像。只有多个画像的可核查增益、MR 不增加、完整度不下降，才晋级；保留无法核实是否语义变化的判分冲突。原稿和评分完全保留，未改文本精确继承旧分，只评分新稿；评分用既有 Qwen 适配，无自动重发，封存集不读。另两个基准此轮无调用。
