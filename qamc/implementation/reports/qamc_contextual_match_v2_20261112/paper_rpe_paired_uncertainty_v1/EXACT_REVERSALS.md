# The three whole-task reversals with an author C

This follow-up examines every reversal in the 110 common contains-C tasks: Always-Task has three whole-task passes, and both IPE-C and Always-Memory have zero. The analysis selected cases by observed scores, so it is a trace audit. The cases represent two conservative source groups. All six endpoint answers match the archived score-answer hashes, and IPE-C selected the full-history answer in each case. The comparison uses the stored GPT-4.1 detailed-adaptation reasons and an execution-side reading of the answers. There is no independent annotation.

These cases reveal disagreements between graded whole-task success and visible behavior. The craft example establishes a concrete protected constraint that the supposedly exact empty answer violates. The diet example needs more nuance: a recommendation can be low-salt and flavorful, and a user's preference need not belong to their parents. No row is relabeled, omitted, or rescored here. The three rows do not estimate the overall judge error rate, and the analysis does not explain the other 107 contains-C outcomes.
