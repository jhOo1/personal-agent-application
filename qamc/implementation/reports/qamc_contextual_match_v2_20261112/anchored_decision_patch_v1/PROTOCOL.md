# Anchored decision patch with a current-evidence control

Reuse the already-exposed RPEval replication cohort of 18 groups and the verified BenchPreS preparation panel of six profiles. Use the exact IPE-C and Gate fallbacks respectively. This is a development diagnostic motivated by observed broad rewriting failures. The underlying cohorts were used for earlier experiments, and no case text is inserted as an example in either prompt. Keep all archived scores, failures, and sealed data intact.

Both arms get one equally capped generation with the same prompt, task, existing strong answer and original chronology. Their only intended input difference is the additional memory dictionary in HISTORY. Each can cite current evidence, and HISTORY can also cite one original history source. It may propose one decision correction, at most two exact substitutions. The program validates a task anchor, chosen evidence origin and literal quote, exact unique nonoverlapping locations, and applies the entire patch simultaneously. All other bytes are retained. A model abstention or exact no-op retains the prior answer. An invalid patch is recorded, with a deterministic return of the original answer. Report these fallbacks separately.

This isolates the incremental value of history under restricted write scope. It differs from the old linked-versus-local comparison where both arms saw the same original history. It also differs from free composition because there is no planner or full-response renderer. Anchor checks are structural. Actors still infer the affected party, applicability, and whether the particular decision warrants repair. Both prompts forbid unsupported general advice, silent relaxation and reframing an individual's preference as a group rule.

RPEval primary comparison uses native-field Match, OPB, UPB and FM, including B/C coverage and case-level evidence. BenchPreS reports AAR, MR, non-bold adherence and completeness under the existing adapter. Exact archived score reuse is allowed; no evaluator swap. Protect frozen references and report all intended denominators and common valid comparisons. Expand only if the history arm improves over same-cost task-only and over fallback, with no material loss on benchmark-specific guards; require actual repairs on at least two groups. Small exposed results cannot establish official SOTA.
