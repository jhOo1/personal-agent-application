# Cross-fitted task prior versus IPE-C
Use the existing 216 exposed RPEval paired answer records. Hold out the complete conservative source group; exclude training records sharing any byte-identical history text with the evaluation record. Raw source text equality is an additional contamination check, not a guarantee of semantic independence. Benchmark-local policy fitting changes no weights and sends no request. Two primary contrasts: strongest available simple task-only prior versus same policy that may condition on the frozen IPE-C binary signal, and original IPE-C versus each. Report all arms, never choose a winner per row.

Fixed rules: global endpoint by total held-in Match margin; a task prior using all training examples with the identical public task request if available, otherwise all nearest query-text bigram Jaccard ties (global fallback if similarity zero). Group nearest candidates by exact request; each tied request contributes its mean endpoint Match difference. The conditional prior first filters training examples to the held-out row's frozen IPE-C signal, then applies the identical task prior, falling back to the unconditioned task prior if this pool is empty. Empty history wins ties. No weights, thresholds or hyperparameters fitted on evaluation predictions. Report IPE-C, always-on and always-off, all-A, at least one B/no C, contains-C, two-endpoint unflagged, severity denominators, available exact matches and weaker row-only same-query references separately. Exposed-data replay; outcomes assess saved answers only. Compare Match with mis/underuse and report all regressions.
