# 强稿中同一决定的旧值可见性对照

三基准共用一种可执行操作。仅以 Query 和当前上下文提取交付义务、可委托决定及各写入位置能承担的职责。随后绑定器可看原稿和原始证据，只能选择已有 ID。对于同一决定，LOCAL_EDIT 和 ISOLATED 接收相同职责、相同的全部已绑定事实和历史、相同的未改正文、相同的写入范围和系统提示。唯一报文差异为待替换位置的旧正文。两臂各一次生成，同时输出所有关联位置；同一编译器写回原稿。FREE 对照接收 LOCAL_EDIT 的材料并可重写整稿。未改正文或选择的 ID 仍可能暗示旧值，程序保证的范围限于显式输入差异与写入位置。各臂以同一个强稿为原点，不添加给当前题的手工任务说明。

固定来源为既有 MAG 的 12 道 RPEval 多偏好 IPE-C 及单独的 V1 早午餐，既有 OPERAND 的 8 道 BenchPreS Strong Gate、8 道 PersistBench SELECTED_GEPA。不同开发轨道分开计分。使用原始候选清单和原评分版本，BenchPreS 沿用强稿的固定事实与 Actor 可见的来源范围。沿用旧分、完整分母和已有的外部对照。早午餐旧 MAG 两臂及 MemAdapter 已成功。生日题 IPE-C 1/8、OPEN 4/8、MATCHED 6/8、RP 7/8。旧 53/79 保护上界仅涉及前三条路径。保险申诉要保住申诉和复议功能，空缺的事实关系不能用收益推定。书友会作为机制反例单列，此 29 题清单不保证收录所有讨论案例。

旧 PUBLIC_WRITE_PARTITION 的编辑器看到全段和全史；按相同修改数量与执行分区比较，全 A 16→29/53、仅 B 32→31/72。SOURCE_LOCAL_REENTRY 给整稿 Actor 一条来源。SLOT_COMMIT 在已生成的段落中选出并拼接，六根 11/30。旧事务修订让同一模型同时选位置与填替换值。本轮只问，写入范围及职责已经共同确定时，屏蔽旧值是否比看着旧值编辑更好。初版机械接线中的整稿/无稿差异已排除出主实验；以 writers.py 构造的同材料对为准。

共同阶段 KEEP 或不覆盖按原稿原分并列报告。已交付但合同无效时登记合同失败及部署回退；服务交付未知的相应路径记缺失。三个新臂共享上游开销，另报各自生成次数。RPEval 同题 Match、OPB、UPB、FM、按 A/B/C，BenchPreS AAR/MR/完整度，PersistBench 各类阈值分与行为。旧评分复用只限同题同一评分协议与同文答案。至少在两个不同来源根同时观察到相对强稿和局部普通编辑的行为和原生改进，完整披露保护项退步及所有缺失后才考虑扩大。若只去除一处无依据事实、书友会等已满分题仅行为改善或只胜自由改稿，保留为诊断。未使用封存集。
