# 任务接口及匹配报文合同

原清单 29 道已曝光开发题全部进入。第一阶段实际 29 次 Qwen 请求，29 个锚点和职责输出通过结构合同，报告 58,641 Token。逐题用第一个可写位置与真实接口构建两条下游测试请求，验证唯一字段差为写入位置的原正文，并把原文提交回原位置，29 道均完整还原底稿。这是机械检查，未给任何测试替换计原生分。

一个可立即定位的风险是 RPEval 生日题 105。只看当前任务的接口列出聚会人数/场地/时段、预算、寿星忌口和准备时长，但没有直接列出由谁做菜或点什么菜。它可能把“需要再确认的信息”和“助手可以代为作出的选择”混为一类。如果这个限制阻断菜单改进，应归入任务接口覆盖，不能全部归咎于后续局部求解器。本轮保持原接口。这条观察读于接口锁定后，未据此改题或替换请求。

实际对照以 writers.py 的 writer_views 为准。两组都看未编辑区域，只对同一位置的旧正文做显隐。trial_oar.py 的 writer_input 用于第一轮机械预检，用全稿/无稿生成的测试视图没有派发。强稿、任务事实和基准评分来源范围见 [协议](PROTOCOL.md)。私有恢复先读 INTERFACE_FROZEN、INTERFACES_PRIVATE、WRITER_FROZEN 以及已有批次回执；execute_writers.sh run 仅接续同一冻结版本。最终成绩需等 WRITER_RESULT_PRIVATE 结算。公开数字不含案例原文或私有报文。
