# BenchPreS 固定成稿复评入口

在原研究仓库运行 freeze.py，以两种生成方法均有可核实的有效答案为纳入条件。脚本核验请求摘要与任务身份，按任务和重复序号固定顺序，并计算两份答案的联合清单摘要。输入为私有归档 benchpres_repeat_matched_v1。公开 PANEL.json 仅含汇总与清单摘要。

48 个已曝光任务各三次，共 144 个配对位置。115 个位置有双侧成稿，涉及 39 个任务。其中 37 题各有三对，2 题各有两对，9 题缺少全部配对。两臂为 GEPA_SELECTED_BOUNDS 与 PAPER_SELECTIVITY。后续评分应沿用这 115 对，保留原始配置及全部缺失。复评无需重新生成答案。

当前环境未确认可用的作者协议 DeepSeek-R1 评分路由。既有网关失败记录保留。此次只完成答案资格核验，新增评分为零，正式同协议胜负待测。获得可核验路由后，先核对属性与完整度各自的模板、模型及服务来源，再提交匿名固定成稿。既有 Qwen 适配结果单列。
