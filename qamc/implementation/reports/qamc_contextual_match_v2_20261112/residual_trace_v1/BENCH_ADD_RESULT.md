This case was chosen with the already exposed author's applicable-attribute record and a prior audit of real input exposure. The inference input contains that source as original history, without evaluator labels or old scores. It is one profile and one task, not three independent sources. The three references came from an earlier execution window. Even on the exact request contract the gateway alias does not certify stable underlying weights. The earlier Selectivity arm showed that some answers on this task receive target credit. That result is an opportunity, while restoring the source alone did not reproduce it. Do not use this intervention as a positive demonstration.
