# Guard a private preference from deciding an open shared choice

This experiment extends the earlier current-commitment comparison. That decision rule required an explicit current value to protect. In four exposed PersistBench risk cases it removed nothing, including a task requesting a reusable project template without specifying a lifecycle. Historical Waterfall preferences then still steered the team default. The comparable RPEval error is a request for a common venue whose suitability was unduly decided by the requester's private tastes. BenchPreS tests preservation of the actual communication deliverable.

A single Qwen call evaluates ordinary relevance first. From the retained sources it separately identifies whether a source would force a personally held default on a currently open decision affecting a different recipient, a group or a public deliverable. The program verifies the source and Query quotes and removes only the verified flagged whole records in the guard arm. A source with another independently appropriate contribution should remain, including valid soft preferences and current participants' hard constraints. The compiler can verify the quotes and record identity, not the underlying semantic judgment. The changed trigger applies to an open value, independent of the old requirement for a conflicting current value. This design is a directly testable increment over the prior negative commitment guard. It does not claim that group scope or selective omission is new by itself.

Reuse the exact old exposed roster construction from the 92-root availability archive: RPEval three all-A and three with B/C, PersistBench four existing matched strong-answer failures and two strict beneficial-use controls, BenchPreS two formal-delivery controls. The same selected sources, task, facts, model alias, Actor text, scoring adaptations and generation parameters are used between the arms. The Actor's sole input difference is the removed sources. Both arms share physical requests wherever the wires are identical. Historic specialists are method references under their archived prompts. No label, UID, grade or old answer appears in inference. The new inference namespace preserves prior failed requests. Outputs and data receipts remain private.

Advance to generation if two distinct roots change their actual Actor request, one outside BenchPreS. For further development require a genuine decision correction on two roots, a positive difference in at least one main benchmark measure against the matched relevance arm, and no observed systematic deterioration in legitimate B/C, beneficial use, or formal task delivery. The guard cannot turn absence of ground truth into a determination that a task rejects a source. Report exact task denominators and transmission or scoring missingness. This is a deliberately selected development test and measures an incremental guard, not a new state-of-the-art result.

Runner commands are `freeze`, `check`, `run` and zero-call `replay`. Load the existing `evo_qamc_fit_v1/run.sh` Python path in the research checkout and execute `trial.py`. Caps are 14 audit requests, 28 Actor requests and up to 48 scoring requests. The prior runner's journal, 3.2-second spacing and zero automatic retries remain in force. Stage-specific private cache snapshots reuse exact historical requests in the same verified service configuration. An exact historical failed or unknown delivery, or an exact receipt with an unverified service configuration, stays unavailable instead of being reissued. Replay uses the snapshots and current journal without dispatch.
