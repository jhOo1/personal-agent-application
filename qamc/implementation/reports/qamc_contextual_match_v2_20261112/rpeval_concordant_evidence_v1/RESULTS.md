## Actual decisions

- **Business Russian, only B.** The ranked arm does not see the role-play history. The agreement arm does and explicitly recommends scenario-based conversation practice and tutoring around the planned trip. Both score 4/5, and all three grades are flagged. This observed useful choice cannot be attributed an original-metric improvement.
- **Qingdao family outing, contains C.** The agreement path restores an applicable interest in older buildings and history. Both route options already include older streets and buildings and restrict close waterfront activity, swimming and boats. Ranked scores 5/6; the agreement path and IPE-C score 4/6. The retained history did not reliably produce a better action, and all recorded C positions survived source compilation.
- **Dormitory instruments, all A.** Ranked leads with quiet and inexpensive instruments without expressly invoking the user's prior drumming. The agreement output still invokes drumming as part of the reason to consider percussion. Both receive 0/5. Agreement on relevance between two estimators still admits memory that should not drive this task.
- **Xi'an family outing, contains C.** Restoring two legitimate soft sources changes which natural settings and food options the answer mentions. Both new paths are 5/9, one below the original full-history strong answer. This does not establish that the lower source count met the full preference/task contract.

Fifteen new Actor calls and fifteen new scores succeeded. An exact old generation and its matching score were reused. The 30 new physical requests reported 73,246 tokens, no unknown usage or resubmissions. Offline replay matched the settlement. All scores are the project GPT-4.1 adaptation and all tasks are already exposed. No independent or human grading, no additional benchmark tasks, and no sealed data.
