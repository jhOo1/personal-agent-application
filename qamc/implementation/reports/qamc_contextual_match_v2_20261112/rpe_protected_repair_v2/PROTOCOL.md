# Protected decision repair on RPEval

V1 recovered two RP misses on an exposed single-preference panel and reduced gratuitous switches. Both V1 and the matched default-aware control reached 18/21 on the strict intersection. All five V1 switch proposals passed the literal validator. V2 tests whether a program that applies only diagnosed decision changes can retain the best parts of RP and produce new answers beyond the three archived candidates.

## Matched experiment

Use all 24 frozen, exposed single-preference tasks. Retain the primary historical 22-task overlap and separately report the full roster, each arm's valid count, and the same-item valid intersection. Current task, fixed facts and raw memory remain unchanged. The three archived candidates retain their original anonymized IDs. Both arms start from RP. V1, Des2Gen, MemAdapter, IPE-C and unmodified RP serve as historical references on the same applicable items. They differ in generation procedure, and the dedicated equal-information comparison is FREE versus PATCH.

Shared location uses one Qwen3.8-flash API call per item. It can keep the original or identify one actual defect and one to five implicated excerpts, which may include dependent sections of the answer. An accepted diagnosis binds its evidence to the task or history and each implicated excerpt to a unique position in the default. Modification requests go only to items with an actionable diagnosis. Consequently the experiment estimates the execution-policy effect under the same locator, alongside any loss from missed or invalid diagnoses. Both arms see the exact same task, history, complete candidates, RP default and validated diagnosis. Each gets one revision request from the same API service at temperature 0 and output cap 8,192. Interleave the paired requests by a frozen hash.

- FREE can keep or revise the whole answer. Its target list is a suggestion, and it can fix other substantive errors.
- PATCH can keep or supply text for every authorized target. DELETE only removes the target, REPLACE changes it in place, and ENRICH retains the target and appends new text. All declared dependent edits commit together. Any bytes outside these locations stay unchanged. The procedure preserves text outside the selected scope, while correctness of the scope and compatibility of proposed content remain semantic judgments made by the model.

Compared with TATR, the model cannot reassemble, reorder or regenerate the whole draft. Compared with DREW and the earlier anchored patch, a shared upstream defect locator grants a fixed write scope before either arm generates the repair. This comparison tests whether granting a limited and jointly executed scope has practical value under the same information and call opportunities. It does not separately identify the value of the diagnosis call relative to a one-call editor. There are no local model weights or case-specific prompt examples.

## Measurement

Generation requests contain only task details, raw history, candidate texts and the generated diagnosis. Author labels, older grades and case-level analysis remain in measurement. Freeze complete final answer and request bindings before reading scores. Exact archived replies receive only their bound grades. A new answer receives the same single-item detailed Qwen RPEval adaptation as the archived candidates. Exact identical scoring requests can be reused. Keep transport failures as missing. A valid abstention, no-op or logged invalid response falls back to exact RP; retain these states separately. Keep prior scoring disputes unchanged.

Maximum physical requests are 24 locator, 48 revision and 48 scoring. The existing durable stage runner records caps, provider identity, transport state and reported usage. Replaying report performs no requests.

The primary comparison is PATCH versus FREE and original RP on common historical tasks using Match, OPB, UPB and FM, by author A/B/C and with the full 24-task denominator reported. For promotion to a larger exposed development cohort, look for gains in two or more distinct sources over RP, at least one net gain over FREE, no loss of previously correct applicable B/C, and behavior review showing the answer still delivers the user's task. Also compare with the frozen V1 and strongest external adaptation on matched items. A score increase driven solely by a known Judge issue is insufficient. If scope-limited edits help but misses dominate, continue by improving the locator; if free revisions act on correct diagnoses more effectively, keep the useful localization and reconsider the executor. This is development evidence under an adapted scoring protocol.
