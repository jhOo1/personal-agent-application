# Prior mechanisms for preserving an answer during repair

RARR separates evidence search, question-guided disagreement detection, and editing. Its editor identifies an affected span and issues a revised passage, with an edit-distance limit described in Section 3.2. The authors also test the cost of extra edits when removing their agreement stage. This supports using an explicit reason to intervene and measuring preservation. QAMC already has the evidence available in frozen history and current task facts. The variable to test is whether those facts authorize a change to a recommendation, ranking, or constraint. A future RARR-style comparator in QAMC would use the same supplied evidence and defect locator, a free rewritten answer, and a predeclared length or edit-distance acceptance rule. It would be an adaptation rather than an exact replication. [RARR, Sections 3.2 and 6](https://aclanthology.org/2023.acl-long.910.pdf)

Self-Refine uses model feedback to improve a preceding output, with no additional parameter training. Its core feedback-and-revision structure is shared by both V2 arms. FREE thus receives the same critique and revision opportunity as PATCH. A gain against the untouched RP answer would establish a development improvement under these inputs. A difference between the two revised arms is needed to attribute a gain to the bounded executor. [Self-Refine](https://arxiv.org/abs/2303.17651)

FAVA localizes several distinct factual defects and trains a retrieval-augmented model to edit them. The useful idea for further QAMC research is to separate unsupported factual inference, an unsuitable recommendation, and missed legal preference use when diagnosing an answer. Each calls for a different action. The V2 API-only implementation uses an evidence-bound runtime diagnosis and a deterministic application step. Its textual guard does not establish the factual validity of a revision. [Fine-grained Hallucination Detection and Editing for Language Models](https://openreview.net/pdf?id=dJMTn3QOWO)

The V2 protocol and inference prompts were frozen before this note. Use these works when evaluating what combination is actually new. Span selection, critique followed by refinement, and minimal editing already have substantial precedent.
