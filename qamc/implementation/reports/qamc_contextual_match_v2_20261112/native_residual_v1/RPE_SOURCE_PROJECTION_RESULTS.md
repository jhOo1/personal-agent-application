# RPEval source projection diagnostic

Three exposed, previously tested hidden-B roots reused the archived whole-source Actor and scorer outcomes. For each, a developer selected one contiguous, exact user statement that retains the relevant preference and its local conditions. The source ID, policy, other request fields and grading protocol were fixed. This is a label-assisted diagnostic, not automatic span selection. There was no length-matched ordinary compression or concurrent resampling arm. The raw spans and requests remain local.

Two roots have valid Match in both arms. On those ten positions, whole input scored 3/10 and projection 7/10. All four additional Match positions are from solo exhibition (implicit/071), 1/5 to 5/5. Its new answer retains the preference for unfamiliar exhibits and explicitly recommends solo-compatible venues. The older answer already offers solo venues and adds previously enjoyed hands-on options. This demonstrates a difference in topics and use of remembered episodes, not verified recovery of all four judged positions. Colleague dinner (implicit/066) stays at 2/5. Total OPB on these two roots goes 4 to 0 and UPB 5 to 3, under the same contested project Judge.

The dinner-for-two Judge returned a Match denominator/range error. Its partial fields are archived and excluded from the paired Match. Six actual requests succeeded at transport, 7,373 reported tokens, no retries. No sealed data used. The single-root gain merits a matched compression and behavior test before developing an online policy.

## Similar-length lexical control

The lexical control chooses a source sentence within 80–120% of the manually projected character length by overlap with query characters. Against this control, projection scored 7/10 versus 3/10 on the two common roots. The same solo-exhibition root accounts for the four-point difference. Lexical extraction selected an assistant question on that root and therefore dropped the user's affirmative preference. For colleagues' dinner, it preserved a user's request for unusual dishes and tied at 2/5. These differences establish that extractive relevance by character overlap can lose speaker and proposition content; they do not separate semantic condition preservation from simply supplying the actual preference. OPB is zero on both common roots in the lexical arm, as with projection.

The dinner-for-two lexical selection unexpectedly matched the projection request verbatim. It was dispatched as a separate draw because the runner lacked a cross-arm request equality check before dispatch. It returned a valid 2/4 while the earlier equal-wire draw had an invalid denominator. Treat it as a duplicate-wire diagnostic observation, not a distinct compression condition. Six physical requests succeeded, with 7,756 reported tokens. All scores and failures remain separate. This small control does not justify a deployment claim.

## Speaker-aware lexical control

The same length window and lexical-overlap ranking were applied only within user turns. Two new request bodies were distinct from projection. Dinner for two again produced the projection body and was skipped before dispatch. All four requests succeeded, with 4,901 reported tokens. The speaker-aware arm scored 3/10, OPB 1 and UPB 7 (projection 7/10, OPB 0, UPB 3) on the two common roots. For solo exhibition it kept an affirmative interest in unusual themes but opened with a reply marker dependent on the omitted question. The selected passage still conveys a preference, so comparison with the earlier assistant-question control no longer explains the entire four-position difference. The two versions differ in proposition scope and sampling, and one source drives all gains. Treat this as motivation to test automatic selection on additional exposed sources, not evidence of stable improvement.

## Automatic extraction comparison on other source groups

Five exposed roots excluded the three manual diagnostic groups. Four contain a separate author-C source whose text and policy were untouched. The same model saw the same numbered passages and half-source character budget in both arms. Conditions added only instructions to preserve semantic dependencies. The requested slots included no author labels. Ten extraction requests returned, of which five elected to retain the whole source, three exceeded the cap (two by three separator characters), and two produced different viable extracts. Both generated answers and both grades succeeded. No repair or resend was performed.

On three common roots (19 positions), archived whole, Ordinary and Conditions each scored 13/19. Two roots were identical whole-source fallbacks; on the third, Ordinary changed the source and tied Match with the Conditions fallback. On the fourth valid root, Conditions changed the source, matched the original 2/3, and Ordinary was over budget. There is no root on which two distinct shortened texts received paired scores. Thus the pilot establishes low effective coverage and no Match gain for either changed answer; it cannot isolate the value of preserving conditions. Fourteen physical requests all succeeded, with 30,242 reported tokens. No sealed data used.

The two extraction replies that exceeded the budget by three characters came from the same root and selected the same IDs in the same order. Reducing separator overhead equally would produce identical Actor inputs. The other invalid reply exceeded its cap by 186 characters and is not a separator issue. There is no overlooked distinct paired intervention recoverable by fixing separator accounting alone. This replay used zero requests and preserves all original statuses.
