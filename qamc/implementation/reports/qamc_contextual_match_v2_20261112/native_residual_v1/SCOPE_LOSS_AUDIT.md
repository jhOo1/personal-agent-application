# 来源筛减失分的逐题归因

RPEval 已曝光仅 B 根 explicit/030，请求是为弟弟推荐不一样的生日礼物。共享计划保留用户的细腻表达、偏好省时和亲手挑选或制作礼物三条相关来源。被移除的五条包括用户爱尝试新科技这一条作者 B，其余四条为作者 A。作者标签只用于事后分析。

- **首次可见的合法证据缺口在计划选择。** 原始完整历史中的新科技来源没有绑定，随后在来源筛减组消失。该兴趣属于请求者；若对弟弟的兴趣未知，不宜将科技当收礼者偏好，可考虑作为条件备选。
- **不能把 5/8→4/8 归因于这条删源。** 完整历史稿本来也没有明确推荐科技礼物，两份稿都包含定制、手写或体验服务。完整稿有可当天完成的手作方案，筛减稿仍按下周期限给建议，但不再同样明确地提供当日完成路线。两次采样的其他内容也发生变化。
- 原评分 OPB 1→2、UPB 2→1、FM 持平。两次 Judge 对预测位置与文字归因的描述都不够明确，不能恢复独立逐位预测，也不能将总分差解释成一条已证实的合法偏好漏用。原分保持不变。

下一对照应分开测试“补回可考虑候选”与“强制采用”，并用同一生成骨干、同一计划与同额请求核对合法软偏好。该题已经用于诊断，不用于确认普遍收益。本次只读已存结果，零模型调用。
