# 作用域计划器的输入核验

计划器从当前 Actor 用户消息中核验可见原文，构造分离的任务事实和历史引用。任务引用可支持交付义务与决定，历史引用仅可绑定已有决定。未匹配到任何原始历史的报文暂不进入调用。测试使用冻结搜索侧有史报文，RPEval 六条均确认可见原文并可构造。BenchPreS 四条仅凭字符串核验未匹配到原历史，Strong Gate 报文中的选择位置与用途说明不能直接当逐字原文。PersistBench 七条以文本模板承载，同样未通过该核验。两个基准需分别核查报文原生序列化与来源合同，不能直接补入完整记忆库存。

本轮未派发模型请求，原结果、评分与封存集未动。首先以 RPEval 为作用域机制的执行入口，再对另两个原生格式验证同输入对照。
