# 非空科学比较与部署决策

原 NRO 对照两臂都回到空策略，留下“哪个非空策略更能迁移”这个问题。新选择接口分别输出最佳完整非空策略和满足保护条件的可部署策略。每个来源组贡献主指标比例差，再对三个基准等权。排序先比较退步子组数，再比较逐组保护项退步计数、等权收益、最差基准收益、策略长度和固定哈希。所有候选缺分保留，缺分者不参加完整策略排序。验证侧仍须在搜索结果冻结后使用。

离线在原搜索结果上验证了该接口。逐条第二份和整块第一份分别排在本臂非空首位，两臂仍无可部署策略。这个事后计算仅用于核验实现，不能替代原冻结结果或作为新方案确认。未派发模型请求、原评分未变、未读取组外结果。下一阶段需冻结共同种子、真实反馈变异和新鲜原生对照。
