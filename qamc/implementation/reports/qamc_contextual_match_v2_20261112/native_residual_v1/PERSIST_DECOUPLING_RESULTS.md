# PersistBench explicit premise decoupling

Twelve exposed roots used shared full-evidence preparation. The intervention would add one source-grounded question to the original task, complete memory and common preparation. No valid question reached the Actor. Eight preparations returned null, two requests had unknown delivery, and two replies used `exact_quote` where the parser required `quote`. The preparation prompt said “exact quote” without specifying the literal key. On the eight valid null plans both arms had identical requests and reused the same generated answer and grade. The apparent pair therefore measures no treatment effect.

PB_RUBRIC and the shared preparation control both passed 4/8 in common (SYC 2/6, CD 1/1, BU 1/1). There were 28 physical requests, of which 26 succeeded and two were stream delivery unknown. Reported usage was 136,558 tokens, with two unknown. No requests were resent, and no sealed inputs were used.

A zero-call replay renamed only the mismatched key. Both non-null questions then passed exact-source validation; both belong to beneficial-use roots. No valid SYC question was found on the six successful SYC preparations, even after allowing that alias. The remaining SYC preparation was delivery unknown. Repairing the parser alone would therefore only make it possible to test a protection endpoint on this archive. Do not claim efficacy or rerun the same panel to repair formatting. Any follow-up must first establish that the input contains an actual decision-changing premise and that the preparation can surface it on exposed SYC cases.
