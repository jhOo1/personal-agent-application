# RPEval soft-preference recovery boundary

The 44/106 physically missing B count is already established by the [exact Actor census](../strong_actor_boundary_audit_v1/READOUT.md). It is a count of author B positions absent from requests, not a count of final answer defects. The task-only route accounts for 26/32 B-only answers in that census. The same audit found one physically absent C out of 118; prioritize generation or declared use when investigating C.

A generic one-source recovery would repeat [source-local re-entry](../source_local_reentry_v1/READOUT.md). That test supplied at most one source in both arms and obtained 55/87 localized, 54/87 full-context and 61/87 exact IPE-C; all-A fell from 30/36 to 25/36 in both new arms. [Corroboration by existing selectors](../ipe_reentry_guard_replay_v1/READOUT.md) also failed to distinguish the four all-A triggers. Preserve both results.

Real cases identify the difference worth testing. In explicit/076 the no-history path physically lacks both B sources and scored 2/8; the alternative contributes specific shade and short walking logistics. In the re-entry 069 example both selectors recovered gamification and repeated a recommendation already present in the task-only answer, while missing pronunciation correction. In the re-entry 063 example selection promoted one person's flexible vegetarian preference to a restaurant default for the whole team. These motivate a concrete incremental-utility comparison: require an actionable improvement over options already present, then test whose decision would change. The exact task-only archive is an offline annotation/comparison tool. An online candidate still needs to justify its runtime cost against an equal-call control. Do not launch another source-local rerun.
