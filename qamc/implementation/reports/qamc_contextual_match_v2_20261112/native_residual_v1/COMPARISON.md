# NRO 两轮同预算对照

两臂从未修改强稿起步，各有两次新候选评估机会。每轮共享一个预写的重点指令。逐条组将它添加到当前获胜策略，整块组整体替换为重点指令及配套指令。每轮环节保留同一搜索面板与档案评分、原生成配置和上限，按完整请求哈希保存或复用响应。这个实验比较固定指令变异，不等同于 GEPA 的开放搜索。先独立于验证结果冻结赢家，再在按根隔离的开发验证面板评价。

同一晋级规则用于两臂。缺分不能晋级，逐题主分、完整度、有益记忆与适用非加粗偏好须保持，误用、漏用、FM 和 MR 不得增加，并且相对当期策略至少有一个主分净增。无候选满足时保留原方法。该严格规则用于检验有保护的增量，结果不外推到所有提示搜索。

最多四份搜索候选与两个验证策略。每份上限 17 Actor + 37 Judge，累计最多 324 个请求；原样复用可减少实际派发。前一单规则试跑不纳入任一臂搜索预算。仅使用已曝光开发库存，原封存集保持隔离。

用 PREFLIGHT.md 所列环境运行 `run_nro_comparison.py check|run|replay`。完整请求、规则选择与评分回执保存在私有 `comparison_v1/` 及请求账本。
