# 旧版外部对照与本次部署的关系

核对已冻结的 29 根和原始 Actor 报文哈希，29/29 在旧档案已有 MemAdapter 最终请求，26/29 保存了最终文本。旧研究同样使用作者提交 6b517dc90d4c7e0ebc4d2305684d45051f792cc9 的三阶段方法。将每个来源的旧 ID、旧二阶段用法和固定原始 Query/Memory 送入本次作者生成模板，29/29 的 system 和 user 文本分别逐字复原。此前已经执行了完整的作者生成路径，论文应明确引用这份归档比较。

这次实验的新增信息是三法同一部署窗口比较、共同终答上限、对风险任务重复部署与固定双评分。旧 Actor 上限全部为 4096，本次各臂均为 8192；旧 ID 体系与新部署在 29 根上均不同。新老成绩的差不可单独归因于 Token 上限或来源编号。归档报文全部保留并单列；这次只计同期部署。作者比较本身不能识别物理遮蔽的独立作用。
