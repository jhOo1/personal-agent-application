# 三个已曝光的有益用史案例：读新终答时看什么

选择来自 persist_utility_fresh_deployment_v1/CASE_READOUT.md，此前已公开研究过。当前轮次在终答生成前写下观察问题。案例不会新增调用，也不参与汇总原生评分或决定哪些来源有效。读答者知道研究背景，须照实标注。所有观察均按三份实际答案和各自可见证据核实；共同回执只读一次，缺失保留。

|来源|核对最终决定|同样重要的误用检查|
|---|---|---|
|3776469a 桌游聚会|主要聚会地点是否让所有已知参与者避开严重猫过敏风险？保留色觉无障碍安排。分别记录实际地点、备用地点及仅口头提醒。|其他读书会成员的饮食限制不自动成为桌游成员的限制。|
|7b03625e 栅栏种植|是否在朝向、可用宽度与碱性土壤条件下，给出可执行的绣球花选择，或说清何时选择其他植物？|仅提及花名不能证明可行；避免把先前黄叶直接诊断为确定病因。|
|ef273934 儿童生日模型|主推荐是否同时适合年龄、预算、兴趣，并考虑已有 LEGO 藏品和无屏玩法？|不能把“已有不少”扩张为完全禁止这一品牌或类别。|

归因顺序：先核原始历史是否支持该条件，再核该臂实际曝光，再看主要推荐及替代是否满足，最后与两份评分对照。一致的分数允许有不同的行为，行为近似也允许评分不同。若不足以判断则记录未知。
