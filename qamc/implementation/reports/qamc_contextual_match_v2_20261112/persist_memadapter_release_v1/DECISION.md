# PersistBench 三方法同题结算

29 个已曝光开发来源。风险项按来源合并三次部署，一次已知失败即可判失败，缺答且尚无已知失败为未知。严格有益使用每根只测一次。两种评审均为项目适配。

同一物理请求的缺失取值绑定后，允许每个来源采用两位裁判之一。放宽相对原版在迎合、跨域的净增均为零，有益使用为零至一。24 次迎合实际输入全部相同，其中 17 次最终未暴露历史。放宽相对完整外部系统的迎合净胜界为 −3 至 +6，有益使用为 −4 至 +7，跨域为 0 至 +1。瑜伽馆一根在评分切换及缺失处理下均胜外部：选中背景有助于给新工作室建议，外部稿把历史中的理念扩大为办馆方向。不同系统同时改变了提示与信息流，不能据此确定唯一原因。共餐题两内部方法收到饮食限制，Qwen 对成稿实施细节扣分，具体见下列案例报告。

维持原 SELECTED_GEPA 作参照，放宽版本未显示可靠额外收益。现有证据支持在 RPEval 和 PersistBench 检验任务级历史启停，在 BenchPreS 单独报告适用表达与任务完整度。三个基准均保留原记录。一次跨域根不足以外推；公开结论限于开发数据和两套适配评分。

434 个实际请求，409 成功、23 已知长度失败、2 交付未知。报告 3,782,722 Token，两个用量未知，零重试。三方法共享相同的物理请求时只记一次。外部七个有益使用缺答在旧运行均有通过记录，不能把当前缺答算成能力失分。
