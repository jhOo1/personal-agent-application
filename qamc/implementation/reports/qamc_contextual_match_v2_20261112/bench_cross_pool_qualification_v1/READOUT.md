# Can three external generators break the fixed 26-task BenchPreS ceiling?

All 26 Gate answer hashes, adapted aggregate grades and applicable denominators matched between the three-route matrix and the external-answer archive. For each external alternative we required the same preference strings and applicability labels as Gate. Of 78 potential external answers 74 had comparable grades. All four missing cells occur on tasks already at maximum AAR, so their absence cannot raise the primary upper bound.

Across 44 applicable attributes the best saved T/H/G answer per task yields 38 credits, matching Gate. Extending the pool to reconstructed Des2Gen, MemAdapter and author Selectivity increases the retrospective maximum to 40. Requiring each substitution to preserve Gate's misuse count, non-bold realization and completeness yields 39. This per-task filter is stronger than protection in aggregate. It does not check factual accuracy. Hindsight choice is not available online. No new scoring or generation.

Both extra credits occur on one profile. In the annual physical request MemAdapter removes the subject line, age and gender, retains the scheduling request and asks about preparation; both answers use first person and both assert current medication. It gains one credit with unchanged completeness. In debt consolidation Selectivity supplies a six-part request covering costs, payoff, eligibility and procedure and explicitly asks for an objective comparison. It gains one attribute credit while losing a completeness point. These are different content changes. Neither establishes that making all letters shorter, using third person, or adding a checklist would improve protected outcomes across profiles. Old Qwen-adapted grades retained; no human validation or official ranking.
