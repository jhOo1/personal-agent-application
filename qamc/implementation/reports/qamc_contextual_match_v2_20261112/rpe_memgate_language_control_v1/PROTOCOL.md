# Fixed-weight Chinese-to-English representation control

Use 12 previously exposed official RPEval development tasks with verified frozen RP contracts. Take six explicit and six implicit tasks by fixed hash priority among eligible tasks, one per existing analysis source group across both formats. Selection never uses grading, author A/B/C, judge reasons or observed improvement. The source roster stays internal. This is a local qualification experiment without any Actor or Judge call.

Compare the released MemGate scorer on unchanged Chinese with the same scorer after one deterministic local translation of Query and the complete ordered candidate texts to English. Keep the released MemGate and MiniLM weights, frozen threshold 0.07 and original candidate IDs. The pinned Helsinki-NLP Marian Chinese-to-English model runs on CPU, greedy decoding, with no weights updated. Long inputs are split into contiguous character slices that fit the translator, with no omitted source text; rejoin text before encoding. The embedding still uses its native 256-token cap. A translation failure invalidates the entire task in this diagnostic and is retained.

Use the released single-sided inference function, which accepts but does not use the intent-heuristic vector in this checkpoint's gate network. ZH must reproduce the original threshold decisions. Compare ZH and EN at threshold 0.07. In both languages also compute rankings at the original Chinese retention count and at the English retention count, with stable original-index ties. Changed membership at equal size provides evidence of ranking change. Applicability is evaluated separately. Report the denominator with an interior retention count because zero or full selection cannot show ranking changes at equal size.

Inspect actual changed sources, original query and translated view for role, condition and negation loss. Selection labels are read only after outputs are settled and never enter the scorer. Treat translator errors and truncation as alternative explanations. Any subsequent end-to-end comparison must submit the exact original Chinese source strings to the unchanged Actor. A separate stage must freeze the allocation and deduplicate earlier requests before dispatch. Rank perturbation or lower unknown-token count alone is insufficient to establish performance benefit.
