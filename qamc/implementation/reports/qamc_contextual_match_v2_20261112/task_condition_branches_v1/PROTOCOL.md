# Preserve genuine decision alternatives under an unknown task condition

The last comparison restricted certain historical clauses but did not change adapted scores. Earlier option ranking compilers and local branch patches did not show a repeatable advantage. This test generates both executable alternatives **from the current task before activating history**. It changes how the Actor is required to commit while sharing the same alternatives, facts and evidence. It uses no weights or predefined benchmark rules.

Use the verified strong-history inputs and 12 exposed source groups from the previous cross-benchmark protected-clause panel (4 RPEval, 2 BenchPreS, 6 PersistBench). These are an already exposed development screen, including a software template, group picnic and necessary constraints. Old responses and scores remain references and are reused on the no-trigger path.

One planner call sees Query, current context and fixed facts only. If it finds an unresolved decision legitimately dependent on a real task condition, it must provide a current verbatim anchor, a criterion distinguishable in practice, and two different complete actions for the criterion present/absent. If the current task already dictates a choice or asks for direct delivery without a materially unresolved decision, it must abstain. Frozen code verifies exact Query anchor, JSON shape, nonempty distinct action text and bounded field length; it cannot verify semantic sufficiency or unknown status. Planner failures stay missing. Both arms see the exact same planner output and original strong Actor memory payload. The constrained arm attaches an operative decision map and requires both branches where the criterion is still unknown; otherwise it renders the applicable action. Free comparison has the same structured information and can use it without having to retain both options. Both make one complete user-facing answer using equal Actor calls. Explicit current requirements and valid hard preferences must hold in both alternatives. Do not invent external option availability. Neither arm sees scores, labels or historical answers.

Report full allocated and genuinely triggered paired subsets separately. RPEval Match, OPB, UPB and FM; BenchPreS AAR, MR, completeness; PersistBench risk and strict BU. At least two distinct source roots must improve the final score against the equal-plan free Actor without an observed loss of necessary task constraints or quality. The gate is a development screen. No native Kimi equivalence, no human judgment and no sealed data. Legacy shape failures, unknown delivery and incomplete scoring remain distinct. No exact earlier request rerun. Maximum 12 planner calls, 24 Actor calls, 8 RPEval, 26 BenchPreS attributes, 12 PersistBench grading calls.
